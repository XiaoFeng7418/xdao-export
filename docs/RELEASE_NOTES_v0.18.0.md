# v0.18.0：批量导出可以断点续跑了——成品已存在的串直接跳过

## 为什么

一次贴几十个串、点开始导出，跑到一半网络断了或者自己要关程序，下次只能把同一批地址再贴一遍。
程序会把已经导出过的串从头重做一遍：长串一份要抓几分钟，十几份就是半小时起步，纯属白等。

## 这版做了什么

- **新增开关「成品已存在就跳过」**：位置在「设置 → ③ 导出」，勾上即可；命令行对应
  `--skip-existing`。勾上之后重新导出同一批地址时，同名成品文件存在且不是空文件的串直接
  跳过，只补没导完的那几个。
- **默认关闭**：不勾时行为和以前完全一样，每次都重导。老配置升级后观感不变。
- **判断标准只看文件本身**：同名成品在、且大小大于 0 字节，就算导过；不看内容、不比对时间。
  所以：换导出目录或换文件名模板就等于从零开始；想重做某一份，把它删掉再跑就行。
- **空文件不算数**：跑到一半被强杀可能留下 0 字节的半成品，这种会重做，不会当成已完成。
- **监控不受影响**：监控每轮本来就该导出新回复，这条开关只作用于手动 / 命令行导出。
- **日志留痕**：开着这个开关时，导出的日志里会多一行「已存在就跳过」，跳过的文件也会逐条
  提示「已存在，跳过：文件名」，不会让人误以为全都重新导了一遍。

## 升级建议

直接用新版覆盖旧版即可，配置与导出结果都不变；这个开关默认关着。
