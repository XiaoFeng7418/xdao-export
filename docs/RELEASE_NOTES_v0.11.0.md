# v0.11.0：出问题之前，先能自己查一遍

这一版加了一个**环境自检**：不用等导出失败，先看看这台机器上程序要用到的东西是不是都就位。

原来命令行里的 `--selftest` 只做两件事：连一下接口、看看导出格式在不在。现在它会先查本机，
再查联网；界面里也加了同一个入口（「运行日志」右上角的「自检」按钮）。

## 自检都查什么

| 检查项 | 看的是什么 |
|---|---|
| 运行方式 | 源码运行还是打包版；打包版会说明给浏览器补了哪个开关 |
| 配置目录 | 放设置与登录状态的地方能不能写 |
| 配置文件 | 能不能读出来；读不出来（坏 JSON、编码不对）会提示删掉重建 |
| 导出目录 | 设过的导出目录能不能写 |
| 缓存目录 | 打算用哪个缓存目录、备选有几个、能不能写 |
| 浏览器 | 找没找到 Edge / Chrome；找不到只影响 PDF，其他格式照常 |
| 导出格式 | 当前能用哪几种格式 |
| 联网（两条） | 接口连不连得上、示例串能不能取到内容 |

- 每一项都给三种结论：`[可以]` / `[注意]` / `[不行]`，后两种还会给一句「怎么办」。
- **只读，不动你的设置**：不会写配置、不会改目录、不会下载东西。
- 命令行：`xdao-export.exe --selftest`（想看本机但不想联网就加 `--offline`；
  想把结果整段贴给别人看就加 `--selftest-json`，输出是 JSON）。
- 界面：主界面「运行日志」右上角点「自检」，结果直接显示在下面，还能点「复制结果」。

## 这一版没有改什么

- 导出、登录、监控这些功能一个都没动，用法与 v0.10.2 完全一样。
- 升级与否都不影响正常使用；下面那个包就是当前最新。

## 下载

- `xdao-export-v0.11.0-win64.zip`（推荐，也是唯一的附件）：**免安装包**，解压后双击
  `xdao-export.exe`；包内附 `诊断写入.ps1` 与 `诊断写入-双击运行.cmd`。
- 单文件版自 v0.5.1 起不再提供：PyInstaller 的单文件版在含中文的路径下会直接报
  `Could not create temporary directory!`，属于打包器的限制，不是程序本身的问题。

## 已知边界（如实说明）

- **PDF 仍然需要本机装有 Chrome 或 Edge**。没有浏览器、路径填错、或者被安全软件拦下时，
  程序会改存 HTML 并说明原因。
- 自检报告里出现 `[不行]` 说明这件事在这台机器上确实没成，但它**不等于程序坏了**：
  比如「浏览器：没找到」时，HTML / TXT / Markdown / EPUB 四种格式照样能用。
- **登录仍需要真人处理一次验证码**：不做自动登录，这一点没有变。
- 打包版才注入 `--no-sandbox`，源码运行（`python main.py`）的浏览器沙箱保持完好。

## 测试

`1007 collected / 1001 passed, 6 skipped`。6 条 skipped 都要显式开关才跑：
`XDAO_BROWSER_TEST=1` 拉起真实浏览器、`XDAO_LIVE_NOTIFY=1` 真弹一次系统通知、
`XDAO_PDF_TEST=1` 用真浏览器渲染 PDF 并核对纸张尺寸。

**真机核验**：打包版免安装包在一台真机上跑过 `--selftest`（本机 7 项 + 联网 2 项全部
`[可以]`，退出码 0），并照旧做了一次真机导出（真实串号、真浏览器渲染 PDF），退出码 0、
256,871 字节、PDF 魔数正确、1 页、`/MediaBox [0 0 612 792]`。

自检报出来的结论是**如实**的：同一次核验里，如果在受限的启动环境里运行（新解压出来的
exe 没有权限写配置目录），「配置目录」那一项就会报 `[不行]` 并给出原因，而同一台机器
里从别的目录运行就全是 `[可以]`。
