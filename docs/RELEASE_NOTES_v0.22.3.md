# v0.22.3：让界面用例在小屏上也能过

功能与 v0.22.1 / v0.22.2 完全一样，产物也一样。这一版只改测试与自动检查配置 ——
上一版把单元测试挪到打包之前，第一次在 GitHub 的 Windows 机器上真跑全套窗口用例，
三条把「左栏多宽、右栏多宽、要不要滚动」写死的用例就栽在那台机器的 1024x768 屏幕上了。

## 原因

- v0.22.2 让打包流程在打 zip 之前先跑一遍单元测试，本意是「坏代码不许打成包」；
- GitHub 的 Windows runner 屏幕只有 1024x768，默认的 `1060x760` 窗口被系统夹到 `1028x728`；
- 左栏内容约 713px 高，装不下，于是真的出现了竖向滚动条（17px 上下）；
- 于是三处断言失准：左栏实测 471（原断言 `452±10`）、右栏实测 473（原断言 `>=480`）、
  `_scroll_needed` 在默认尺寸下变成 True（原断言恒为 False）；
- 这三项在较大显示区域下通过 —— 测试环境使用较大显示区域，窗口未受限，因此未触发滚动条。

## 改了什么

- **只改 `tests/test_window.py` 的三条用例**，产品代码一行没动：
  - 左栏宽度：断言落在「设定宽度 ~ 设定宽度 + 24px」之间（多出来的就是滚动条）；
  - 右栏宽度：断言「吃掉窗口宽度减左栏宽度以外的全部宽度」，不再写死 480；
  - 「装得下就不滚动」：先把窗口设回 `1060x760` 再断言，语义回到「默认尺寸下不滚动」；
- 其余一律不动：导出行为、命令行开关、配置项、文件名模板都与 v0.22.1 相同。

## 读数

- 测试：2813 项，本机 2806 通过、7 项真机用例默认跳过（与 v0.22.1 相同）；
- 自动检查：三条 run 恢复全绿（构建 / 主干测试 / 标签测试），Windows job 第一次真跑全套用例。

## 升级建议

已经在用 v0.22.1 或 v0.22.2 的话，不必为这一版重新下载 —— 功能完全相同。
只有想留一份「检查全绿」的存档时才需要换。
