# v0.13.43：最后一批「谁报的」句子扫干净

## 现象

仓库是公开的。README、发布说明、`packaging/使用说明.txt`、`MAINTENANCE.md`、源码注释和用例的
文档字符串里，还留着一些**复述来源**的句子：「有用户用 0.13.26 报……」「0.13.26 的用户报……」
「按用户 2026-10-04 的定案……」「2026-10-02 那位用户的导出目录……」「（用户截图 m39918）」这类。
这条规矩 v0.10.2 就定过，v0.13.14 与 v0.13.16 又各补过一轮 —— 但后来几版新写的文字里又混了进来。

## 改法（只改文字）

31 处、13 个文件：

| 落点 | 处数 | 例子 |
| --- | --- | --- |
| `packaging/使用说明.txt` | 4 | 「有用户用 0.13.26 报」→「0.13.26 的现场是」；「另外按用户要求」→「另外」 |
| `README.md` | 2 | 「有用户用 0.13.26 报」→「0.13.26 的现场报」；「有用户用 0.13.25 复验」→「0.13.25 复验时」 |
| `MAINTENANCE.md` | 9 | 「（用户截图 m39918）」→「（现场截图 m39918）」；「按用户……的定案」→「……定案」 |
| `xdao/gui.py` | 3 | 「用户报问题时贴的是运行日志」→「遇到问题时贴的是运行日志」 |
| `xdao/exporters/_shared.py` | 2 | 「2026-10-02 那位用户的……可他拿」→「2026-10-02 那台机器的……可同一台机器拿」 |
| `HANDOFF.md` | 1 | 「已按用户……的定案从路线图删掉」→「已于……定为不做、从路线图删掉」 |
| 用例文档字符串（4 个文件） | 6 | 「真机上（用户报告）」「用户报的那张页面」「用户报问题时贴的是运行日志」 |
| 发布说明 v0.13.42 / v0.13.27 / v0.13.25 | 4 | 同步改掉，并按仓库里的文件重新推一次 Release 正文 |

保留不动的两类：讲规矩本身的那几段（`MAINTENANCE.md` 的「## 注释与文档的写法」、README 里那条
规矩的引用块，以及 v0.10.2 / v0.13.14 / v0.13.16 的发布说明），和「用户截图时看不见」这种泛指
说法 —— 它没点谁报的。

## 真机核验

- 全仓按句式复查（「有用户」「有人反馈」「有人报」「收到反馈」「用户报」「用户要求」「按用户」
  「用户截图」逐条看）：剩下的命中只有上面那两类。
- 逐文件字节复查：`packaging/使用说明.txt` 仍是 UTF-8 BOM + 纯 LF，`README.md` /
  `MAINTENANCE.md` / `HANDOFF.md` 仍是 CRLF 且没有裸 LF，`xdao/gui.py` 仍是纯 LF。
- 只动注释、文档字符串与说明文字，没有行为变化；收集数与上一版相同（1820 项）。
