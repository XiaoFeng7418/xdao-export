# v0.21.0：多个串可以合并导出成一个文件

这一版给批量导出加了一个可选项：**把这次导出的所有串写进同一份文件**。默认关闭 ——
不打开它，程序的行为、文件名、日志都和 0.20.0 完全一样。

## 为什么

一个串一份文件适合「收集」，不适合「阅读」：想从头到尾读完一批串，得在十几个文件之间
来回切。合并成一个文件之后，一次滚动就能读完，也方便直接发给别人。

之所以做成开关而不是直接改默认行为：已经有人的目录里按「一个串一份文件」整理了几百份
成品，改默认会把它们全打乱。

## 这版做了什么

- 「设置」新增「把这次导出的串合并成一个文件」，命令行是 `--merge`。
- 支持 HTML / TXT / Markdown / PDF 四种格式：
  - HTML：一份文件，每串一节，标题区写「第一个串标题 等 N 个串」；
  - TXT / Markdown：用分隔线把串隔开；
  - PDF：只渲染一次，整批串连成一份 PDF。
- 合并文件的名字自动带「等 N 个串」，不会和单串文件撞名；「成品已存在就跳过」
  同样认这个名字。
- EPUB 是单个 zip 包，不支持合并：选了它会提示一句，然后按一个串一份文件保存。
- 合并中途点「取消导出」，已经写出的单串文件保留，合并文件不会留下半成品。

## 升级建议

直接用新的免安装包覆盖旧目录即可，配置与缓存都兼容。不勾「合并导出」就不用改任何习惯。
