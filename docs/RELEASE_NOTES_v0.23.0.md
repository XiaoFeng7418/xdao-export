# v0.23.0：改进双栏界面与深浅配色

这一版更新了 Windows 桌面界面。左栏集中填写串网址和导出选项，右栏显示进度与运行日志。可以在顶栏切换浅色、深色和界面字号。

## 这版做了什么

- 主窗口和对话框采用统一的配色和控件样式。左栏宽度随界面字号和系统缩放调整，间距也随系统缩放变化。
- 调整了设置、登录和串监控窗口的文字布局与控件间距，使用键盘切换控件时，焦点边框更容易辨认。
- 修复 Windows 保留名带扩展名时的导出问题。比如 `NUL.txt` 会改为 `NUL_.txt`，下划线加在第一个点前。
- 更新中英文 README，补充下载、使用指南和反馈入口，以及浅色与深色的实机截图。
- Windows 自动检查要求实际打开 Tk 窗口并运行界面用例。窗口无法初始化时，测试会失败。

## 验收范围

本次验收范围为离线逻辑与真实 Tk 桌面界面。X岛服务异常，真站导出验证暂缓；这些检查不代表当前站点登录、抓取或导出已恢复。站点恢复后的真站验证另行补做。

## 附件

- `xdao-export-v0.23.0-win64.zip` 是 64 位 Windows 免安装包。解压后双击 `xdao-export.exe`，无需安装 Python。
- `xdao-export-v0.23.0-win64.zip.sha256` 是配套的 SHA256 校验文件，用来核对下载的 ZIP。
