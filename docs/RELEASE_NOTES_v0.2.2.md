## 本次更新

修一个会**白等很久**的坑：导出目录写不进去时，程序会把整个串抓完（长串要五六分钟）才在
最后一步报错，而且报的是一句看不出所以然的 `PermissionError`。

### 现在的行为

- **开口就拦**：开始抓之前先探测导出目录与缓存目录能否写入，不可写就立刻停下，
  并说明原因与出路（换目录、改权限，或关掉缓存）；
- **缓存失败不再静默**：以前缓存写不进去会被悄悄忽略，用户以为抓取成果已留存，
  结果下次还得重抓一遍。现在会明确警告「本次抓取不会被复用」；
- **错误信息可读**：不再是裸的 `[Errno 13] Permission denied`，而是指出是哪个目录、
  可能是什么原因、可以怎么办。

### 顺带说明

如果你遇到的正是「抓了很久最后报 PermissionError」，多半是导出目录的 Windows 权限
不允许当前账户写入（可在文件夹属性 → 安全里授予「完全控制」）。本版仍会报错，
但会在开始时就告诉你，不再浪费那几分钟。

### 功能（与 v0.2.1 相同）

- 四种导出格式：HTML（图片内嵌）/ TXT / Markdown / EPUB；
- 断点续传与增量更新：33 页 / 626 楼的长串第二次导出只花 1 次请求；
- 图片缓存、只看指定饼干、文件名模板；
- 串更新监控：定时检查新回复并自动导出；
- 可配置代理、请求间隔、超时与重试（429 / 5xx 指数退避）；
- 191 个离线单元测试。
