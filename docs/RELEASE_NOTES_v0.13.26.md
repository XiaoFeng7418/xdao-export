# v0.13.26：等登录时不再空转，也不再什么都不说

这一版只修「用浏览器登录」这一条路上的两处哑巴结局；界面、导出格式、配置文件、
命令行开关都没动。

## 一、那条 HTTP 路可能一整轮都没试过

0.13.25 为了省请求，把「走 HTTP 领饼干」的闸门设成「饼干罐变了才试」。设计时的假设是
「用户一登录，罐子一定变」—— 可真机上站点登录完可能只换会话饼干的**值**：名字没变、
也没多出新饼干，指纹看着就是没变。于是程序从第一次到最后一次都没试，对话框里只剩
「浏览器里的饼干：PHPSESSID、memberUserspapapa（还没有 userhash）」，运行日志里连一条
登录记录都没有。

现在闸门有两条腿：

- 罐头一变，**立刻**试（用户刚登录完，这一步最要紧）；
- 罐头一直没变，也每隔 30 秒试一次 —— 一趟十分钟最多三十来个请求，换来「一定留下痕迹」。

## 二、每条结论单独占一行，并当场进运行日志

以前那条路的结论只会去顶替那行常驻提示（「这个窗口里还没登录」），用户截图时看不见它。
现在它有自己的位置：

- 对话框里多一行「领饼干那条路：……」，写出站点或网络层说的原话；
- 同一句话**当场写进运行日志**，用户不必等到超时那句话才看得到。

另外，饼干名单里若有**空值**的饼干也会点名：站点把会话饼干写成空壳时，罐子看着
「登录过了」，其实一个真会话都没有 —— 而「罐里算不算登录着」正是以前判断「要不要去领饼干」
的依据，判错的代价就是整轮一次都不试。
