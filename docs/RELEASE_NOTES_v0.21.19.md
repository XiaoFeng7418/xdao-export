# v0.21.19：静态检查清掉几处隐患

这一版不改功能、不改界面、不改导出结果。只做一件事：把没人走到过的代码
用静态检查过一遍，然后清掉几处「后一份把前一份盖住了」的影子代码。

## 为什么

上一版修的那处崩溃（EPUB 书名的兜底函数里少了一个导入），是靠真机导出才撞出来的。
这类问题的共同点是：**代码就在那儿，但正常跑不会经过它**，所以编译、导入、
全部用例都报不了——只有真撞上才炸。这版先用静态检查把它们提前捞出来。

## 找到的

- `tools/sync_from_api.py`：一整份脚本忘了 `import json`，`api()` 一调用就
  `NameError`。它的用例全都把 `api` 整个顶掉，所以这一行从来没被执行过。已修，
  并补了一条直接调 `api()`、核对回包能解析成字典的用例；
- 被后来者盖住、从没生效的影子代码：`tests/test_client.py` 里的 `_FakeResponse`
  写了两份、`tests/test_window.py` 里的 `_drain` 写了两份、`xdao/browser_login.py`
  里本地那份 `Frame` 与几个帧协议常量被文件末尾的兼容出口盖住——都删掉了；
- 协议层搬去 `xdao/cdp.py` 之后留下的 7 个未用导入，以及 `pdf.py`、`txt.py`、
  `tools/` 里几处未用导入。

## 加了一条守卫

新用例用标准库 `ast` 扫全仓：同一个文件里同一个顶层名字绑定了两次就报红。
上一版丢的那条用例（同名用例写两遍，前一份从没跑过）正是被这一类问题吃掉的，
而它不会再靠人工看出来了。

## 读数

- 测试：2670 项，本机 2663 通过、7 项真机用例默认跳过；
- 新增 2 条用例；产品代码只做减法（删死代码、删未用导入）；
- 界面与导出结果与上一版逐字节一致。

## 升级建议

对使用者没有任何变化，可以不换。

## 附件

免安装包（Windows 64 位）：解压即用，不用装 Python、不用装依赖。
换版本时直接覆盖原目录即可，配置与缓存不在包里。

- `xdao-export-v0.21.19-win64.zip`（@package_info@）
- `xdao-export-v0.21.19-win64.zip.sha256`（SHA256：`@sha256@`）

下载后解压覆盖原目录即可；配置与缓存在 `%APPDATA%\xdao-export` 与导出目录里，不会被覆盖。
