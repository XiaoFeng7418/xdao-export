# v0.10.2：改了两处措辞

这一版**没有改功能，也没有改行为**，只改了源码里两处说明文字：把「用户报…」「用户要求…」
这类写成了「遇到…」「指定的…」。这类复述来源的写法放在公开仓库的注释里读着别扭，
换掉即可；程序一个字节的行为都没变。

## 改了哪两处

| 位置 | 原来 | 现在 |
|---|---|---|
| `--pdfdiag` 诊断工具的开头说明 | 「用户报……时」这种句式 | 「遇到……时」 |
| 缓存目录候选顺序的说明 | 用户要求的位置永远排第一 | 指定的位置永远排第一 |

两处都在注释/帮助文字里，功能与命令行、界面行为都不受影响。

## 你需要做什么

- **不必升级。** 如果你手上是 v0.10.0 或 v0.10.1 的免安装包，功能上与本版没有任何差别；
  这一版只是让公开的代码读起来不再像在引用谁的反馈。
- 想拿一个"最新"的包：下载下面这个附件即可，用法与 v0.10.1 完全一样。

## 下载

- `xdao-export-v0.10.2-win64.zip`（推荐，也是唯一的附件）：**免安装包**，解压后双击
  `xdao-export.exe`；包内附 `诊断写入.ps1` 与 `诊断写入-双击运行.cmd`。
- 单文件版自 v0.5.1 起不再提供：PyInstaller 的单文件版在含中文的路径下会直接报
  `Could not create temporary directory!`，属于打包器的限制，不是程序本身的问题。

## 已知边界（如实说明）

- **PDF 仍然需要本机装有 Chrome 或 Edge**。没有浏览器、路径填错、或者被安全软件拦下时，
  程序会改存 HTML 并说明原因。
- **登录仍需要真人处理一次验证码**：不做自动登录，这一点没有变。
- 打包版才注入 `--no-sandbox`，源码运行（`python main.py`）的浏览器沙箱保持完好。
