## 本次更新

### 新增 PDF 导出

除了 HTML / TXT / Markdown / EPUB，现在可以直接导出 **PDF**：

- 调用本机 **Chrome 或 Edge** 的无头模式渲染，**不需要装任何额外软件或 Python 库**；
- 图片全部内嵌、中文字体**子集化嵌入** —— 文件换到别的机器上也能正常显示和打印；
- 页眉页脚已关闭，直接沿用网页版的打印样式，适合归档和打印。

```powershell
python main.py 67024789 -f pdf -o D:\备份
# 自动找浏览器；也可以显式指定
python main.py 67024789 -f pdf --pdf-browser "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

实测：33 页 / 626 楼 / 269 张图的长串导出为 **408 页 / 157.9 MB** 的 PDF，字体与图片均已内嵌。

### 修掉「失败时一声不吭」的问题

长串导出失败后，控制台只说"成功 0 / 1"，**看不到任何失败原因**。
现在：

- 失败原因会**同时写进导出目录下的 `xdao-export.log`**，含时间、格式、每个串的抓取与导出结果；
- 终端汇总里会明确提示「以上失败原因已写入…日志」；
- 导出成功的文件也会在日志里记下**体积**。

### 顺带的改进

- 导出完成后会打印文件体积，不用再去文件夹里看；
- CLI 新增 `--pdf-browser`、`--pdf-timeout` 选项；设置里也能指定浏览器路径；
- 测试从 191 项增至 **213 项**，新增覆盖 PDF 导出器（用「假浏览器」验证完整调用链）与命令行入口。

### 已知限制

- PDF 由浏览器渲染，串很长且图片很多时会比较慢、体积也大（上例 157.9 MB）；
  体积敏感时建议用 TXT / Markdown，或先用 HTML 格式再自行打印。
- 导出 PDF 需要本机装有 Chrome 或 Edge；两者都没有时程序会明确提示并建议改用 HTML。
