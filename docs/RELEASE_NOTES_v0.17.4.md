# v0.17.4：点一次「用浏览器登录」不再冒出一串窗口

v0.17.3 修掉的是「窗口还在启动、调试端口没答话，程序看不见它、又开一扇」。真机上
（2026-10-18）还剩另一半：浏览器会把页面交给真正承载窗口的那个进程，`Popen` 记下的
启动进程自己以退出码 0 先退出 —— 而程序只认「那个进程还活着」，于是判成「刚起来就
退出」，换下一份资料目录再开一扇。候选表里五份目录，桌面上就是五扇窗。

这一版在「启动进程退出」那一刻先回头看一眼：那份资料目录的 `DevToolsActivePort` 如果
是这次启动写的、端口此刻真答话（或者启动前就有一扇开着、这一趟把页面交给了它），就
把这扇窗直接认下来，收尾也按资料目录收干净；只有端口也不答话，才照旧判失败、换下一个
候选。

界面、导出格式、配置文件、命令行开关都没动；本版只修这一处缺陷。
