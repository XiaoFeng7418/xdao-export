# v0.13.36：钉稳你真正登录的那一页 —— 对账行再把浏览器「此刻有哪几页」列出来

## 该下哪个附件

下载 **免安装包** `xdao-export-v0.13.36-win64.zip`（解压后双击 `xdao-export.exe`，不需要装
Python）。同一页还挂着一份 `xdao-export-v0.13.36-win64.zip.sha256` —— 那是给上面这个包核对
用的校验文件，不是程序，不用解压。

## 这一版改什么

v0.13.35 的窗口号上了真机（m37565），这一把把两个老嫌疑都审死了：横幅末尾的【窗口号】和
对话框报的**号对上了**，Alt+Tab 也只有一扇带横条的窗口 —— 不是登错窗；而未过滤的整罐读
（`全罐=1`）里**真的只有 1 块 PHPSESSID** —— 也不是域名/分区（CHIPS）把 userhash 挡在了
程序外面。饼干的罐子每 1.5 秒都在重读、晚登录也会被当场抓住，可整罐就是没有 userhash。
结论只剩一个：**这次登录没有把饼干提交进这扇窗的罐**——窗口里显示的那页「饼干列表」，
只是上次登录留下的缓存画面。另外程序自己也有一处可疑：对账行的「挂=」在两页之间来回跳
（一页僵尸登录页、一页可见的饼干页），说明重挑标签时在两页间摇摆。

这一版把这三件事一起改掉：

- **钉稳**。重挑标签的规则改成：只要当前挂着的是一个**活着的非登录页**站点页面，就不再
  动它；只有挂的是登录页、而浏览器里另有站点页时，才挪过去一次。不会再两页来回跳。
- **对账行加「页=」清单**。`读罐对账` 那行多一段 `页=N（这页地址｜那页地址…）`：浏览器
  此刻有哪几页、各挂在哪个地址，一行看全 —— 僵尸标签一眼可见（只写地址，照旧绝不写任何
  饼干值）。配合「挂=」并排，两页摇摆无所遁形。
- **话术掰正**。领饼干失败的收尾句和两分钟那句提醒，都不再引导「你多半登错了窗口」，改
  说真话：「程序一直在读这扇窗的罐，罐里确实没有 userhash —— 多半是这次登录没提交成功；
  窗口里留着的那页『饼干列表』只是上次登录的缓存画面。请在这扇窗里回登录页，重新提交
  账号密码验证码。」

界面布局、导出格式、配置文件、命令行开关都没动。

## 下载后核对一下

把 zip 和 `.sha256` 放同一个文件夹，在 PowerShell 里：

```powershell
Get-FileHash .\xdao-export-v0.13.36-win64.zip -Algorithm SHA256
Get-Content .\xdao-export-v0.13.36-win64.zip.sha256
```

两行的字符串一样就是原件。
