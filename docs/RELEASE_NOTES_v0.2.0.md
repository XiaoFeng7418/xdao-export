## 本次更新

### 新增导出格式

- **Markdown**：便于二次编辑、贴到博客；保留标题、饼干、时间、No.、引用楼层索引与图片链接。
- **EPUB 3**：可直接导入阅读器的电子书，纯标准库手写实现（`mimetype` 首条且不压缩、manifest 与目录完整、楼层 XHTML 全部合法）。图片支持**内嵌 / 仅链接 / 丢弃**三种模式。

### 速度

- **断点续传**：页面按串缓存，中断后再跑只补缺页。实测一个 33 页 / 626 楼的长串，第二次导出**只花 1 次请求**。
- **增量更新**：接口报出的回复数没变时直接用本地缓存，不重复翻页。
- **图片缓存**：同一张图只下载一次，跨次导出复用。

### 监控

- **串更新监控**：盯住若干个串，定时检查新回复并自动导出；没有新回复时每轮只花一次请求。
- 可选「校验老楼层改动」，发现被编辑的楼层也会重新导出。

### 易用性

- **只看指定饼干**：界面里可从当前串第一页勾选要保留的发言人。
- **文件名模板**：`{title}` `{id}` `{date}` `{po}` `{count}`，例如 `[{id}] {title}`。
- **命令行模式**：无界面批量导出、监控、`--selftest`，便于脚本与计划任务。
- 失败重试（超时 / 429 / 5xx 指数退避）、失败清单一键重跑、可配置请求间隔与代理。

### 修复的问题

以下 8 个问题都是本轮通过单元测试与真实数据发现的：

1. 命令行传入纯数字串号会直接崩溃；
2. 第 1 页从未写入缓存，导致缓存永远"不完整"、断点续传只有表面效果；
3. 楼层指纹比对方式错误，每次校验都误报「楼层被编辑」；
4. 同一个串按两种格式监控时，第二种会被永久跳过；
5. HTML 导出会静默丢弃正文里无法识别的标签（正文中写的 `<script>` 会整段消失），现改为转义后保留为可见文本；
6. Markdown / EPUB 忽略文件名模板；
7. `.gitignore` 的 `_*.py` 规则把所有 `__init__.py` 都忽略了，导致包无法被导入 —— 三个 `__init__.py` 此前从未进入版本库；
8. `Post.image_url` 是一个永远返回 `None` 的死属性。

### 工程化

- 182 个**离线单元测试**（覆盖缓存、监控、四种导出器与配置），无需联网、无需账号即可运行。
- 导出器拆分为 `xdao/exporters/`（公共基础 + 四种格式），消除多处重复实现。
- 补充 MIT 许可。

## 使用提示

- 串越长收益越明显：首次导出会逐页抓取，之后依赖缓存会快得多。
- 图片全部内嵌会让 HTML / EPUB 体积很大（600 多楼的图串可达数百 MB）；体积敏感时用 TXT / Markdown，或把 EPUB 图片模式设为「仅链接」。
- 请遵守 X 岛的使用规则，控制抓取频率，导出的内容仅供个人备份。
