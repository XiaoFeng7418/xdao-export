# v0.13.13：把「为什么是个空浏览器」讲清楚

## 现象

「用浏览器登录」打开的浏览器窗口，和平时使用的 Edge 不是同一份资料目录：窗口里没有已装的
扩展，也没有保存的密码（含浏览器密码管理器里存的那份），看起来像另一个软件。

## 原因

是同一个 `msedge.exe`，只是**换了一份资料目录**（插件、保存的密码、Cookie、历史都存放在资料目录里）。
而且从 Chrome/Edge 136 起，官方**不允许在默认资料目录上开远程调试端口**（为防「用远程调试偷
Cookie」），想读登录饼干就必须带一个非默认的 `--user-data-dir`。所以程序只能另开一份干净的临时
资料目录，那个窗口里自然没有你平时装的插件和保存的密码。

参考：https://developer.chrome.com/blog/remote-debugging-port

## 改法（只改文案，登录逻辑没动）

- 「用浏览器登录」窗口开头改成 7 行说明：干净的一次性窗口、没有插件和保存的密码、请用 X岛账号
  登录一次（跟微软账号无关，不要输微软密码）、程序只取一个登录饼干、关掉窗口后临时资料就删掉、
  你自己的浏览器一点也不受影响；不想重输就点「直接粘贴饼干登录」。
- 「直接粘贴饼干登录」从系统输入框换成自家窗口：先讲清**程序不会去翻你自己浏览器的数据**（插件、
  保存的密码、登录状态都不碰），再把复制的三步写全 —— ① 按 F12 打开开发者工具；② 选「应用程序 /
  Application」→「Cookie」→ 点 `https://www.nmbxd1.com` ；③ 找到 `userhash` 那一行，复制它的「值」。
  整段 cookie 也认，程序会自己把 userhash 摘出来；粘进去没有 userhash 时窗口留在原地提示，不用重开。
