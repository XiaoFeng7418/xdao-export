# v0.22.1：把几个能踩到的坑修掉

这一版没有新功能，做的是「照别人的用法真去用一遍，把绊脚的地方填平」：不登录时界面拦着不让导、
最小窗口下按钮压住整块设置、一页网络出错整串白跑、串号敲错却被告知一个不相干的理由、
串标题撞上 Windows 保留名导出失败。顺带把 EPUB 成品的体积和 CI 的几处缺口收掉。

## 为什么

- `packaging/使用说明.txt` 写着「不登录也能用，但只能读到每个串的前 100 页」，
  命令行也一直是照常导的，可界面点「开始导出」直接弹「请先登录或设置饼干」就返回了 ——
  同一件事三种说法；
- 窗口拉到最小 940x680 时，「开始导出」按钮压在「导出目录」卡片上，缓存占用那一行
  被盖住；那块内容不在滚动区里，滚也滚不出来；
- 抓页时某页网络出错会直接抛出来，整趟导出中止。长串抓到第 70 页断一次，前面全白抓；
- 串号敲错（`abcdef`）时提示「串号截止把列表里的串全都挡住了」，还返回退出码 0 ——
  脚本里根本看不出这一趟什么都没导；
- 串标题正好叫 `CON` / `PRN` / `AUX` / `NUL` / `COM1` 这类 Windows 保留名时，
  写文件会失败（`FileNotFoundError` / `FileExistsError`），提示还看不出原因；
- 正文里的字面尖括号（像 `<3`）被当成 HTML 标签吞掉；
- EPUB 内嵌图片时同一张图存了两遍（`OEBPS/images/` 一份 + 正文 data URI 一份），
  体积是应有大小的 2.01 倍；
- PDF / EPUB 的「图片」下拉框里还露着「存到同名目录」，选了不生效，只在日志里说一句；
- 没装 tkinter 的机器上，命令行连配置都读不进来（`theme.py` 顶层导入 tkinter 失败）；
- CI：`build.yml` 打包前一条用例都不跑，卡住的运行没有超时上限，依赖版本也没钉。

## 改了什么

- **不登录也能导**：界面改成问一句「现在就登录吗」，选「否」照样开始，日志写一行
  「只能读取每个串的前 100 页」；
- **左栏底部不再重叠**：滚动区从 `pack` 改成 `grid`（同一个容器里 pack 与 grid 混用，
  两者各画各的）；代价是最小窗口下真需要滚一下，用例改成断言「滚动区覆盖全部内容、
  底部按钮不压住它」；
- **单页出错不中止**：现抓那一页失败就记进缺页、跳过继续，收尾照旧补抓一遍；
- **串号解析收紧**：`"0"`、`"12345abc"` 不再当串号；命令行认不出串号时逐条报到 stderr，
  说「一个串号都没认出来」并以退出码 2 结束（被 `--until` 挡光也是 2）；
- **文件名兜底**：控制字符一律替换，命 Windows 保留名时加下划线；
- **正文标签正则**：只认 `</?字母…>`，字面尖括号不再被吞；
- **EPUB 不重复存图**：内嵌模式的正文本来就是 data URI，不再另写 `OEBPS/images/`；
- **图片下拉框按格式给选项**：PDF / EPUB 只露「内嵌图片 / 仅保留链接 / 丢弃图片」，
  主窗口与「编辑监控」都改了；
- **没有 tkinter 也能读配置**：`theme.py` 的三个 tkinter 导入包了 `ImportError` 兜底；
- **CI**：两个 workflow 加 `timeout-minutes`、`cache: pip`，钉 `pytest==9.2.0` 与
  `pyinstaller==6.22.2`；`build.yml` 打包前先跑一遍单元测试；`tools/build_zip.py` 的
  `--version` 冒烟从「打印出来」改成「必须报出这次打的版本号，否则判失败」；
- **文档**：README 下载段补第一次双击的 SmartScreen 提示；自检里那句
  「导出目录：还没选（首次导出时会让你选一个）」改成「还没设置，默认用『文档\X岛备份』
  （不存在会自动建）」——界面其实一直预填着它，从来没弹过选择框。

## 读数

- 测试：2813 项，本机 2806 通过、7 项真机用例默认跳过；
- 这一版新增 11 条用例：抓取层 3（单页出错不中止、串号 `"0"` / `"12345abc"`）、
  命令行 2（认不出串号、混合清单）、界面 4（不登录照样导的两条、底部不压滚动区、
  图片下拉框随格式变）、设置 1（没有 tkinter 也能读配置）、仓库门面 1（CI 超时与先测试）；
- EPUB 内嵌模式的成品体积回到应有大小（以前 2.01 倍），有用例钉住「不再写图片文件」。

## 升级建议

值得换，尤其是习惯不登录只看公开串、或者常抓长串的。换版本直接覆盖原目录即可，
配置与缓存不在包里。
