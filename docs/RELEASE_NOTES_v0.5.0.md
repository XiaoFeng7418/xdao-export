# v0.5.0：界面全面重做，看起来像 2020 年代的程序了

发布时间：2026-09-30

这一版只做一件事：把界面重做一遍。功能一个没改，但窗口从「一列灰控件堆到底」
变成「顶栏 + 左栏设置 + 右栏日志」的两栏布局，配色、字体、圆角、控件尺寸统一由
`xdao/theme.py` 管，四个对话框也跟着换了同一套风格。

## 界面变化

- **主窗口改成两栏**：左边是「① 输入串网址」「② 导出目录」两张卡片 + 底部主按钮，
  右边是大块「运行日志」。窗口默认 `1060x760`（原来 `840x840`），宽屏下日志看得更全；
  最小尺寸 `940x680`，1366x768 的笔记本也放得下。
- **顶栏**：标题 + 一句话能力说明（HTML · PDF · TXT · Markdown · EPUB | 断点续传 · 图片缓存 · 更新监控）
  + 状态胶囊（绿点「已登录」/ 灰点「未登录」）+ 三个入口按钮。
- **统一的视觉语言**（全部在 `xdao/theme.py`，只有一份色值）：
  - 亮色 / 暗色两套调色板，代码里不再散落 `#3b82f6` 这种硬编码；
  - 字体自动探测（Windows 用 Microsoft YaHei UI + Consolas，macOS/Linux 有对应回退）；
  - 间距统一按 4px 的倍数取（`theme.gap(n)`），圆角卡片用手绘 Canvas 实现，
    不再用「1px 浅色边框假装阴影」的老办法；
  - 主按钮、次要按钮、文字按钮、危险按钮四档样式；输入框聚焦时主色描边。
- **自绘控件**（`xdao/widgets.py`）：圆角 `Card`、状态胶囊 `StatusPill`、圆角进度条
  `ModernProgress`、多行文本 `FlatText`、小标题 `SectionHeading`。
- **四个对话框一起换装**：登录、设置、挑选饼干、监控串更新。设置对话框改成三张卡片
  （网络 / 缓存 / 导出），说明小字用统一的淡色；挑选饼干原来横向被裁，现在按 440x440 排好；
  监控窗口底部那 3px 溢出也修了。
- **左栏内容装不下时会滚动**（鼠标滚轮可用），不再把底部按钮顶出窗口。

## 顺手修掉的两个真问题

- **`CardFaint.TLabel` 之前不存在**：主窗口两处小字用了这个样式名，而主题里没配，
  ttk 会静默回落到默认 `TLabel`（在白色卡片上就是一块灰底）。现在真的配上色了。
- **`Card` 的宽度曾经写死**：内层画布一直用 `tk.Canvas` 的默认宽 378px，
  结果是所有用卡片装内容的对话框都被钉死在 410px 宽，文字再长也只会被裁掉。
  现在卡片会跟着内容（含 `wraplength` 提示文字）变宽。

## 界面截图

仓库里新增了开发期截图工具 `tools/gui_shot.py`（纯标准库：GDI `BitBlt` 抓像素 +
`zlib` 手写 PNG），改动界面后可以自己抓图核对，不用装任何截图依赖。

## 下载哪个

- **推荐**：`xdao-export-v0.5.0-win64.zip`（免安装包）。解压后双击里面的 `xdao-export.exe`
  就能用，不需要装 Python；`_internal` 文件夹要和 exe 放在一起，别单独把 exe 拖出来。
- 单文件版：`xdao-export-v0.5.0.exe`。只有一个文件、方便携带，但它在系统临时目录
  不可写的环境里会打不开（报 `Could not create temporary directory!`）。遇到这种情况
  请改用上面的免安装包。
- 免安装包里的 exe 从这一版起改叫 `xdao-export.exe`（以前叫 `X岛串导出工具.exe`）。
  中文名的 exe 在个别工具链里会被截断或乱码，换成 ASCII 名字更稳；程序本身没有变化。

## 升级提示

- 配置格式没变，旧配置文件直接兼容。
- 导出功能完全没动：命令行用法（`xdao-export.exe <串号> -f pdf` 等）与之前一模一样。
- 打包版仍然无法导出 PDF（见 v0.3.1 说明），需要真 PDF 请从源码运行。

## 测试

- 离线用例 **290 项通过、1 项跳过**（跳过的是需要真机通知的 `tests/test_live_notify.py`）。
- 新增 `tests/test_theme.py`（19 项）：调色板字段完整性与对比度、间距是 4 的倍数、
  字体探测、样式配色与状态映射、圆角顶点。
  注意踩过的坑：`tk.Tcl()` 这种纯 Tcl 解释器里**没有 ttk 包**，测样式必须用真 `tk.Tk()`。
- 新增 `tests/test_window.py`（13 项）：主窗口标题与最小尺寸、左右栏宽度比例、
  底部按钮与进度条在默认/最小窗口下都完整可见、日志框只读且等宽、EPUB 图片行随格式收起。
  这组用例复用的是同一个根窗口（本机连开十几个 Tk 根窗口偶发创建失败），
  并且把 `AppSettings.load()` 换成隔离配置，绝不碰用户真实的 `%APPDATA%`。
