# v0.14.1：补齐开源协议、版权声明与免责声明

## 这一版改什么

这一版没有动功能，只把「这个项目按什么协议给你用、版权归谁、出了事谁负责」写清楚 —— 并让
**这些声明真的跟着免安装包一起发出去**。

### 1. 协议与版权

- 仓库根目录本来就有 `LICENSE`（MIT 全文）。这一版把版权行补全成
  `Copyright (c) 2026 晓风 (XiaoFeng7418)`（原先只写了 GitHub 账号）。
- `README.md` 新增 **「开源协议与版权」** 一节：是 MIT 许可，点明可以自由使用、复制、修改、
  合并、发布、分发、再许可与出售（**包括商业用途**），唯一的条件是保留版权声明与许可声明；
  并写明打包版里带的 Python 解释器（PSF）、Tcl/Tk（BSD 风格）与 PyInstaller 启动器（GPL，
  另带「可用作商业程序启动器」的例外条款）各自的许可随包保留。

### 2. 免责声明

`README.md` 新增 **「免责声明」** 一节：非官方（与 X岛揭示板及其运营方没有任何隶属、合作、
赞助、认可或授权关系）、按「现状」提供且不带任何担保、请只导出自己有权查看的内容并用于个人
备份与阅读、请保持默认抓取频率并遵守岛规、导出内容的版权属于 X岛平台与原作者、责任限制，
以及权利人可随时通过 issue 联系处理。

### 3. 随包发出 LICENSE

`tools/build_zip.py` 的打包清单加上 `LICENSE`（包内文件名 `LICENSE.txt`）。MIT 要求
「版权声明与许可声明」随软件的**每一份副本**一起走，所以它必须跟着 exe 发出去；从这一版起，
解压出来的文件夹里就有这一份。随包的 `使用说明.txt` 也补上对应的两条，并说明协议全文就在
同一个文件夹里。
