# v0.20.0：Markdown 的图片也能存到同名目录，清单文件一次读进一批串

这一版加两样小东西，都不改默认行为：不打开它们，导出结果和 0.19.7 一样。

## 这版做了什么

1. **Markdown 支持「图片存到同名目录」**（`--image-mode folder`，界面里的「图片」下拉框选
   「存到同名目录」）。图片写进成品旁边的 `<成品名>.files/` 目录，正文改成相对路径的普通
   Markdown 图片语法：文件本体只有几十 KB，图片还是本地文件，离线能看，发到博客或仓库里
   也能直接显示。默认仍是「仅保留链接」。
2. **串号清单文件**：把要导出的串写进一个文本文件（一行一个串号或网址，空行与 `#` 开头的
   行忽略），命令行加 `--input 清单.txt`，或点界面里输入框右边的「从文件…」。同一串号只导
   一次、按文件里的顺序来；清单里只要有一行认不出，就整体拒绝并指出是第几行——不会悄悄少
   导几个。清单和命令行里写的串号可以一起用。
