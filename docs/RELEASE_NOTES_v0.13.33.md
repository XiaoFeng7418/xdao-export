# v0.13.33：程序到底在看哪个窗口 —— 现在窗口自己会说话

## 该下哪个附件

下载 **免安装包** `xdao-export-v0.13.33-win64.zip`（解压后双击 `xdao-export.exe`，不需要装
Python）。同一页还挂着一份 `xdao-export-v0.13.33-win64.zip.sha256` —— 那是给上面这个包核对
用的校验文件，不是程序，不用解压。

## 这一版修了什么

真机复验 v0.13.32 时撞上的冤案（m35762/m35800）：有人**就在程序弹出的那个窗口里**登录、
还在「我的饼干」列表点了「应用」，程序照样抓不到饼干 —— 而且「每次手动点应用都抓不到」
几乎贯穿这个功能的历史。这不是人漏了步骤，是程序自己的锅，这一版三管齐下：

- **程序窗口全世界只留一个**。以前每点一次「用浏览器登录」，程序都可能开出一个**新的一模
  一样的窗口**：上一个窗口还开着、长相相同、里面还登录着 —— 人很自然地就在旧窗口里操作，
  可程序盯的是新窗口的饼干罐，两边永远错开。现在再点「用浏览器登录」，如果之前程序开的窗口
  还活着，会**直接接上那个窗口**，不再另开新的；日志会写明「接到之前开着的程序窗口上了」。
- **被盯的窗口自己会说话**。程序看的标签页顶上从此钉着一条**棕色横条**：
  「串导出程序正在看这个窗口 —— 请在这里登录 X 岛；登录后到「我的饼干」列表里点一行
  『应用』」。横条每轮重钉一次，页面跳转了也不会掉。没有横条的窗口（你自己的浏览器、
  或上一次留下的旧窗口），登了也白登 —— 这件事从此不用靠文字猜。
- **界面上每一句话都补上了「点应用」**。登录只给会话饼干，`userhash` 是点了「应用」之后
  才会出现的那块 —— 这一步以前从没写在等待话术里，是误会的一半。现在等待状态、超时收尾、
  两分钟提醒、对话框开头、使用说明，全部写明「登录之后还要到『我的饼干』列表点一行『应用』，
  看到『饼干切换成功』程序才拿得到」。

顺带修了一处谎报：程序挂的那个标签如果不在站内页面（比如停在空白页），以前领饼干那条路
会撞上去被站点弹回登录页，然后把「这个窗口里的登录没成」栽给用户；现在会诚实说出
「程序挂的这个标签现在不在 X 岛页面」，不误伤。

## 界面、导出格式、配置文件、命令行开关

布局和 0.13.32 一样，没有新增也没有改位置；变的是上面这些等待话术、棕色横条，和
「用浏览器登录」接手旧窗口的行为。

## 下载后核对一下

把 zip 和 `.sha256` 放同一个文件夹，在 PowerShell 里：

```powershell
Get-FileHash .\xdao-export-v0.13.33-win64.zip -Algorithm SHA256
Get-Content .\xdao-export-v0.13.33-win64.zip.sha256
```

两行的字符串一样就是原件。
