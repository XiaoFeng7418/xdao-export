# v0.13.8：自检里把浏览器真启一次

`--selftest --check-browser` 会在原来那几项后面**真的启动一次浏览器**（临时资料目录，
试完立刻关掉），回答「用浏览器登录」这条路到底通不通。

## 这一版改了什么

- **自检多一条「浏览器启动」**：加 `--check-browser` 后，自检会在本机各项之后真的把候选
  浏览器挨个启一次。能起来的报「能起来」和调试端口答话用了几秒；起不来的写明**退出码**，
  常见的是安全软件把浏览器进程或本地调试端口拦下。
- **只要有一个起得来就算通过**：现场遇到的正是「默认那个起不来、另一个能用」，只报第一个
  失败会让人以为整条路都废了。都起不来时最后一条会直接说「本机这些浏览器都起不来，
  『用浏览器登录』暂时用不了」，并给出三条建议（看安全软件、换设置里的浏览器、
  改用「直接粘贴饼干登录」），退出码 1。
- **不加这个开关时，自检仍然只读** —— 一个浏览器都不会启动。
- 顺带修掉打包使用说明里被复制过的一段文字（v0.13.6 那段的正文多了一份）。

## 什么时候用它

点「用浏览器登录」没反应、或者窗口一闪就没了，先跑：

```
xdao-export.exe --selftest --check-browser
```

它会当场告诉你：哪个浏览器起得来、哪个起不来、起不来的退出码是多少。界面里也有同样
的入口：「运行日志」右上角「自检」对话框底部的 **「试浏览器」** 按钮。

只想查浏览器这一件事，用 `--check-browser`；想输出 JSON 贴出去，加 `-json`。
