# v0.21.4：给主窗口的几条动作补用例，失败时也得说话

## 为什么

主窗口上有几条「平时都绿、出问题才会被看见」的动作：清空缓存、环境自检里的联网两项、
发现新版本后问要不要下载、开监控前的两个拦路检查。它们此前一条用例都没有，而它们共同
的失败方式恰恰是最难被发现的：**不报错、也不提示，看起来像什么都没发生**。

## 这版做了什么

只补测试，不改任何用户能看到的行为。`tests/test_window.py` 53 → 63（真 Tk）：

1. 清空缓存：当前没有缓存时提示「当前没有缓存。」；用户点「否」时一个文件都不动；
   确认删除时目录消失且日志写「缓存已清空」；删除失败弹「清空失败」并带上原因
   （不会假装已经清空）。
2. 环境自检的联网两项：每条结果都写进自检面板；探针自己抛异常时也照样写进去
   （不能静默吞掉）。
3. 发现新版本后：「打开下载页」走对分支；打不开浏览器时把网址记进运行日志。
4. 开监控前：没有监控目标、或没选导出目录时给出提示，且不会真的进入监控状态。
