# v0.13.9：「用浏览器登录」改用临时资料目录

这一版修的是「自检里浏览器明明起得来，点『用浏览器登录』却一起来就退」——
报错里写的是 Edge **退出码 21**。

## 为什么

v0.13.8 的自检能查出「浏览器起不来」，而实际现场正好相反：

- 自检里 Edge 明明「能起来，Edg/154.0.4258.48，调试端口答得上话（0.4 秒）」；
- 点「用浏览器登录」却一起来就退。

两条路唯一的差别是**浏览器资料目录**：自检走的是全新的临时目录，「用浏览器登录」走的
是配置目录里那个从上次登录留到现在的旧目录。旧目录里的会话状态坏掉之后，浏览器会拒绝
启动，而每次换一个空的就没事。

## 这一版改了什么

- **每次登录都开一个全新的临时资料目录**（系统临时目录下，名字里带进程号和毫秒），
  关掉登录窗口后**自动删掉**，不在系统临时目录里攒垃圾。
- 界面会写明「这次用的是临时资料目录（…），关掉登录窗口后会自动清掉，不影响你自己的
  浏览器」。
- 关窗时把这次启动的浏览器**整棵进程树**收干净（渲染、GPU 子进程也一并收）：浏览器是
  多进程的，父进程退出不等于子进程都走了，它们会按着临时目录不放。**只收自己启动的
  那一个** —— 按命令行里的资料目录路径匹配，你自己开着的浏览器窗口不受影响。
- 「退出码 21」那句报错补了说明：这个码常常是「进程已经退出、收尾时才报出来」，未必是
  崩溃原因；同时写明多半是资料目录的旧状态坏了、或者被安全软件拦下。
- **登录失败的原因会写进运行日志**了（「浏览器登录没成：…」）。以前它只写在登录小窗口的
  一行小字上，窗口一关就没了 —— 贴出来的运行日志里一条登录记录都没有。顺带说明：
  这条路一直有「直接粘贴饼干登录」可以用。

## 兼容性

- 设置、配置格式、缓存都没变，直接覆盖升级即可。
- 你在自己浏览器里的登录状态不受影响：登录窗口用的是独立资料目录，本来就不碰你的浏览器。
