# v0.12.0：旧版本会自己告诉你有新版了

以前想知道有没有新版，只能自己来仓库的 Releases 页面看。这一版起，程序会替你问一声。

## 它怎么工作

- **启动后 1.2 秒**悄悄问一次 GitHub，把「有没有更新」写进运行日志；有新版本时，
  「运行日志」右上角的按钮会从「检查更新」变成 **「有新版本」**，点一下就问你要不要打开下载页。
- **24 小时内只问一次**：结果缓存在配置目录里，同一天反复开程序不会再发请求。
- **手动查不吃缓存**：点按钮或在命令行敲 `--check-update`，一律现问一次。
- **只发一个请求，不带任何本机信息**：问的是发布页那个接口，只读回最新版本的版本号与链接。
  没网、代理不通、接口将来改了，都只是安静地跳过，**不会影响导出**，也不会弹错误框。

## 命令行

```powershell
python main.py --check-update
python main.py --check-update-json
```

查不到时退出码仍然是 0（查不到新版不是程序出错），JSON 里会写明原因。

## 代理

按「环境变量（`HTTPS_PROXY` 等）→ Windows 系统代理设置 → 直连」的顺序试；这条顺序和你
导出时用的是同一套。

## 这一版没有改什么

导出、监控、PDF、登录都没动。**不升级也完全没影响** —— 只是不会有人提醒你出新版而已。

## 下载

免安装包：`xdao-export-v0.12.0-win64.zip`（解压后双击 `xdao-export.exe`，不用安装 Python）。

## 已知边界（如实说明）

- 只认「版本号比现在大」这种情况。发布页上的预发布版本（如果有）也照版本号比。
- 认不出的版本号一律当成 0.0.0：宁可不说「有新版本」，也不瞎报。
- 查版本失败（没网、代理不稳、接口改版）只会安静跳过，**不会**告诉你「查询失败」以外的任何事，
  也不会挡住导出。
