# v0.19.0：图片可以存到成品旁边的同名目录——HTML 本体不再背着几十 MB 的图片

## 为什么

图多的串（截图楼、表情楼）导出成 HTML 时，图片是按 base64 塞进 HTML 本体的：一个 600 多
楼的图串，成品能到几百 MB。这样的文件：编辑器打开要等半天、微信 / QQ 发不出去、
网盘也传不上，想只发文字部分都做不到。

## 这版做了什么

- **「图片」下拉框多了一项「存到同名目录」**：命令行是 `--image-mode folder`。选了它，
  导出 HTML 时图片写进成品旁边的 `<成品名>.files/` 目录，正文用相对路径引用，HTML 本体
  只剩几百 KB。
- **图片仍是本地文件**：断网也能看，双击 HTML 直接打开；发给别人时把 `.html` 与
  `.files` 目录一起带上就行。
- **文件名可读**：图片按原 URL 的词根命名（重名自动加序号），想翻某张图可以直接在目录里找。
- **只对 HTML 生效**：PDF 是内存里渲染成一张张页面，没有「同名成品」可以放图片；EPUB 本身
  是单个 zip，也不适用。用这两种格式时选它，会按内嵌处理，日志里有一句说明。
- **默认仍是「内嵌图片」**：不选它的话，行为和以前完全一样。

## 升级建议

直接用新版覆盖旧版即可，配置与导出结果都不变；想用新模式就在「图片」下拉框里选。
