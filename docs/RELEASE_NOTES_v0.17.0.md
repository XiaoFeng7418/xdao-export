# v0.17.0：导出可随时取消、监控条目能原地改

## 改了什么

1. **导出随时能停。** 导出过程中「开始导出」按钮会变成「取消导出」，点一下就停 ——
   正在抓的那一页、正在下的那张图收手就停，已经导出的文件都留着，
   汇总里写「取消前完成 N / M 个串」。停止位是总闸：抓取层、各导出器、
   PDF 走命令行渲染时都认同一个位，PDF 渲染会立刻收手而不是干等到超时。
2. **监控条目能原地改。** 串监控列表里选中一行点「编辑选中」（或双击那一行），
   就能改这一条的范围、导出格式、图片处理与最多页数，改完立刻存盘；
   串号本身不给改 —— 换串是另一条监控，删了重加更清楚。
3. **图片下载有进度。** 图多的串在下载期间每完成 10% 报一行，不再看起来像卡住。
4. **修一处真机乱码隐患。** 用浏览器登录时问 powershell 拿到的资料目录，
   在中文 Windows 上不再变成乱码（旧的解码方式已经换了，按系统代码页兜底）。

不动设置的话，导出成品与以前一致。
