# v0.17.5：多扇窗再出现时，运行日志能对账

这一版**只加日志，不改任何行为**。

## 为什么

v0.17.4 修的是「浏览器窗口活过了启动进程、程序没认下它，于是又开一扇」这条根因。
但真机上很难复现 —— 修完回验时只正常开出一扇，没法当场证明已经修好。

以前候选表里的中间失败全被内部消化掉：运行日志里只剩最后成功那句「开窗前普查……」，
一扇窗试了几个资料目录、每一扇为什么放弃，事后一个都看不到。再碰到「一次点击弹出好几扇」，
只能靠猜。

## 这版做了什么

- 每一次候选尝试失败（换临时目录、换备用目录、换浏览器），运行日志里多一行：
  第几扇没成、用哪个浏览器、开在哪份资料目录、为什么放弃。
- 顺序就是真发生的顺序：先看到哪几扇没成，最后才是成的那扇。
- 界面、导出格式、配置文件、命令行开关一律没动。

## 升级建议

装了就完事 —— 它不影响任何现有功能，只是把「看不见的尝试」记下来。
下次真机上再碰到一次点击弹出好几扇窗，把运行日志（「保存…」按钮）发给我，
日志能直接指出是哪一扇开的。
