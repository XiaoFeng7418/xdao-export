# v0.16.0：图片处理补齐、EPUB 下图提速、监控可限页数

## 这一版改了什么

**一、HTML 与 PDF 也能选图片怎么处理。** 以前只有 EPUB 有「内嵌 / 仅链接 / 丢弃」三选一，
HTML 一律把图片压成 base64 塞进文件，PDF 只能跟着 HTML 走。现在三种格式共用一套：

- 左栏「导出格式」旁边多了「图片」下拉框：内嵌图片（默认，离线可看）、仅保留链接（不下载
  图片，体积小）、丢弃图片；
- 命令行是 `--image-mode embed|url|drop`，对 HTML / PDF / EPUB 都生效；
- 选「仅保留链接」时**根本不去下图片**，大图串的体积与导出时间都能降一个量级；
- 图片下载失败很多时，日志只逐条列前 10 张，再多就汇总一句（以前是一张一行刷屏）；
- TXT 与 Markdown 是纯文本，没有这一项。

**二、EPUB 的图片改成并行下载。** 以前一张接一张地下，图多的串导出慢好几倍。现在六路并行，
落盘顺序仍按正文里第一次出现的先后，**同一个串导两次的结果仍然一致**。没下到的图片会在
导出结束时汇总一句「有 N 张图片没下到，已从电子书里去掉」。

**三、监控的每一条可以各自限「最多页数」。** 加进监控列表时，把当时「最多页数」记在这一条
上（0 = 不限，与手动导出的语义完全一样）：

- 监控表「范围」列直接写明「全部 · 最多 5 页」，不用点开猜；
- 每一轮检查都按这一条自己的页数抓，长串长期挂着也不会每轮翻完；
- 监控列表导出成文件时会多存一个 `max_pages`，导入时认不出会逐条说明原因；
- 想改某一条的页数：删掉重加（加的时候取当前输入框里的值）。

**默认行为没有变**：图片仍是内嵌、监控条目不填页数就是不限 —— 不动设置的话，导出成品与
上一版一致。

## 这一版的自查

- 全量用例 **2005 passed / 7 skipped**（收集 **2012** 项；比上一版多 22 项，都在图片模式、
  EPUB 并发下图与监控限页数这三条线上）；
- 布局回归用例在最小窗口（940x680）下复核过：新加的「图片」下拉框并进「导出格式」那一行，
  不额外占高度，界面仍不需要滚动条；
- 契约用例（文档事实、版本号一致、使用说明分段、文本卫生、打包清单、公开材料、命令行文档）全绿；
- 逐文件行尾复查：`README.md` / `MAINTENANCE.md` / `HANDOFF.md` 仍是 CRLF，`packaging/使用说明.txt`
  仍是 UTF-8 BOM + 纯 LF。
