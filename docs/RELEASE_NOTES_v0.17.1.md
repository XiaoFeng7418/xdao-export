# v0.17.1：导出与监控不再同时跑、PDF 超时预算补了用例

## 改了什么

1. **导出与监控互斥。** 这两件事都要往同一个导出目录写成品、往同一份缓存里追加页，
   同时跑会互相踩（同名产物互删、缓存写到一半被另一条盖掉、进度条按错的数字跳）。
   现在一件正在跑时，另一件点了会提示「正在忙」，先停下来再开。
   顺带收口了监控状态：监控线程收手（正常结束、出错、用户点停止）之后，
   界面状态立刻落回「未启动」，不会再出现写着「监控中」、后台其实没人在跑的情形。
2. **PDF 超时预算补上用例。** 起浏览器、连调试端口、等页面加载、打印四段等待共用
   同一个截止时刻（v0.17.0 里已经改成这样，这次把行为钉进用例）：每段拿到的秒数
   不超过剩余预算、也不超过该段自己的上限，预算用完时下一步立刻报超时而不是再等一轮。

不动设置的话，导出成品与以前一致。
