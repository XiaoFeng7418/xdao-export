# v0.21.17：合并导出的 PDF 有书签目录了

这一版不改界面、不改按钮，只让导出的 PDF 多一份书签目录：合并导出的 PDF 在阅读器左侧
能按串跳转，不必一页页翻。

## 为什么

合并导出会把这次导的几个串写进同一份 PDF，几十页、上百页很常见，而 PDF 阅读器里的
书签栏一直是空的——想知道「哪一页是第三个串」只能自己翻。浏览器的打印引擎其实支持
按页面里的标题生成书签，只是默认关着，两条渲染路径都没开。

## 这版做了什么

- 命令行渲染路径（默认走这条）加上 `--generate-pdf-document-outline`；
- CDP 渲染路径（改了纸张 / 边距 / 方向 / 缩放时才走）加上 `generateDocumentOutline`；
- 老版本浏览器不认这个参数时，自动去掉它再打一次：宁可少一份书签，也不让整趟导出失败。

书签由浏览器按页面里的 `h1` / `h2` 生成：合并导出每个串一条，标题就是成品里那一节的名字
（例如「1. 某串」）；单串导出是串标题一条。层级之外的内容不进书签，所以列表不会太长。

## 读数

- 测试：2622 项，本机 2615 通过、7 项真机用例默认跳过；
- 新增 4 条用例：两条路径都带上了参数、老浏览器拒绝时退让重打、重打也失败时报错；
- 实测：两个串合并导出的 PDF 里有 3 条书签（合并标题 + 两个串），点一下直接跳到对应页。

## 升级建议

常导 PDF 的可以直接换。旧版本导出的 PDF 没有书签，想要的话重新导一次即可，其余行为不变。
