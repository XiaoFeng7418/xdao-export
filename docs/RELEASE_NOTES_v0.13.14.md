# v0.13.14：文档和注释里不再写「谁报的」

## 现象

README、发布说明和 `使用说明.txt` 里，有不少句子是**先把「谁报的」写出来**：开头一句
「有用户问：……」「有人反馈：……」「有人报过……」，后面才接现象；更早的几版还有把反馈人
称作「这位用户 / 那位用户」的写法。源码注释里也有「用户报的是……」「用户报的就是它」这类
把来源当正文的句子。

仓库是公开的，这类句子把「谁说的」当成正文，读起来啰嗦，也不像产品文档。

## 改法（只改文字）

- 把「谁报的」删掉，直接写现象与规则：不复述来源的原话、不点来源、不带日期。原来那种
  「有用户问：……」的开头，整句换成它描述的那个现象本身就好 —— 例如「「用浏览器登录」
  打开的浏览器窗口，和平时使用的 Edge 不是同一份资料目录：窗口里没有已装的扩展，也没有
  保存的密码（含浏览器密码管理器里存的那份），看起来像另一个软件。」
- 覆盖：README（3 处）、`packaging/使用说明.txt`（3 段）、`docs/RELEASE_NOTES_v0.13.13.md`
  / `v0.13.12.md` / `v0.13.9.md`（2 处）/ `v0.13.7.md` / `v0.6.1.md` / `v0.6.0.md` / `v0.5.3.md`
  / `v0.3.0.md`、MAINTENANCE（2 条）、`xdao/browser_login.py` 与 `xdao/gui.py` 的注释、
  `tests/test_window.py`（2 处）/ `tests/test_gui_entry.py` / `tests/test_gui_browser_login.py`
  的文档字符串，共 25 处。
- 界面上原来有「有没有遇到过：把『环境自检』窗口拉窄一点…」这种口语化开头，一并改成直接描述。
- 规则本身（「## 注释与文档的写法」）和泛指假设场景的句子保持原样。

功能、界面布局、导出结果与 0.13.13 完全一致。
