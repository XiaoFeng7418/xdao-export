# v0.13.25：拿不到饼干时不再「什么都不说」，等登录也不再空转着连站点

这一版只修两处真机上才看得见的地方，外加把用途与声明写进公开材料；
界面、导出格式、配置文件、命令行开关都没动。

## 一、拿不到 userhash 时，程序不再沉默

0.13.24 复验「用浏览器登录」：弹出的一次性窗口里**已经登录成功**
（自己打开 `…/Member/User/Cookie/index.html` 能看到自己的 5 块饼干，每行都有「应用」），
可对话框里只写着「浏览器里的饼干：memberUserspapapa、PHPSESSID（还没有 userhash）」，
一个字都不提程序接下去试了什么、站点回了什么。

原因：站点从导出页正文里抠出来的那块饼干，值里可能夹着**二进制字节解出来的字符**；
而程序当时的判断是「必须全是可打印 ASCII 才算一块饼干」（`looks_like_userhash()`），
真值就这样被判成「不像」，然后被**静默丢掉** —— 那条分支返回的空串诊断，等于没说话。

现在：

- 粗筛只挡一眼就不是值的东西（空白、分号、尖括号、成句的中文）；真假交给站点去认
  （请它验一次这块饼干）。
- 万一还是被挡下来，程序会写下它的**形状**（几个字符、几个非 ASCII、几个百分号、开头是什么），
  **不写值本身** —— 那是凭据，不该进日志。
- 「一块 X 岛的饼干都没读到」和「站点既没给值也没给原话」也各留一句，不再有空白的诊断。

## 二、等登录的那几分钟，不再空转着连站点

以前「用浏览器登录」对话框开着的时候，程序每 5 秒就去连一次站点领饼干，哪怕浏览器里的
饼干罐根本没变 —— 一趟登录最多两百来个请求全打在空气上。现在先算饼干罐的指纹，
**只有罐头真的变了**（登录完了、站点换了会话饼干）才去试。

## 三、用途与声明

README 与免安装包里的 `使用说明.txt` 都新增了「用途与声明」：本工具用来把你有权查看的串
导出成离线文件、**请勿用于违法用途**、导出内容的版权属于 X岛匿名版与原作者，并列出岛规、
官方使用指南与免责声明三条链接；同时写明程序默认怎么爱惜站点（请求间隔、重试、退避、缓存）。
