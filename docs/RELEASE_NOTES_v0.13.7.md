# v0.13.7：修「登录窗口里明明登进去了，程序却没登录上」

## 出了什么事

有人报过：点「用浏览器登录」，浏览器窗口弹出、在里面正常登录 X 岛，程序也像成功了
—— 可导出的时候全是未登录的内容。

原因不是登录本身，而是**「算不算成功」这条判据太松**：

- 浏览器用的是**独立资料目录**，而且这个目录是**留着的**。上一次登录留下的
  `userhash` 饼干还在里面，会话其实早就失效了。
- 旧版本只要在浏览器里**看到** `userhash` 这块饼干就宣布「登录成功」、把窗口关掉。
  于是旧的、没用的饼干被当成新登录结果交了回来。

## 这一版怎么改

拿到饼干之后**先问一句服务端**：

- 拿这块饼干去请一次用户系统里的「饼干」页（只读一次，不发任何写操作）。
- X 岛不认这块饼干时，会把请求弹回登录页 —— 这就是判据。
- 不认的话：**窗口不关**，在窗口上直接说清「这块饼干 X 岛不认（多半是上一次留下的
  旧饼干，也可能这个账号还没在「饼干」页领过）」，请你在浏览器窗口里重新登录一次。
- 网络不通之类的**不算**「饼干不认」：那种情况只说「没法确认这个登录还算不算数，
  程序会接着试」，不会误导你去重新登录。
- 验过、当场能用的饼干会记下来，不会每 1.5 秒重复去问服务端。

顺带把这一步做成了自成一体的函数：它自己会把这块饼干装进请求里再问 ——
以前要靠调用方先装一次，漏了就变成「拿着别人的身份问」，结论会反过来。

## 没改什么

导出、配置、升级流程、命令行开关、界面布局都没动。「用浏览器登录」的兜底
（换资料目录、换浏览器）也照旧。退路一直在：窗口上的 **「直接粘贴饼干登录」**。

## 升级以后怎么拿到这一版

**已经装了 v0.13.6 的不用手动下载**：等它自己提示「有新版本」，点一下按钮就行。

## 下载

免安装包：`xdao-export-v0.13.7-win64.zip`（解压后双击 `xdao-export.exe`，不用安装 Python）。

## 还是登录不上

- 窗口上写「这块饼干 X 岛不认」→ 就在那个浏览器窗口里**重新登录一次**；要是还不行，
  去 X 岛用户系统 →「饼干」→ 领取并应用一块饼干（有些账号没领过，就没有可用的饼干）。
- 窗口上写「没法确认这个登录还算不算数」→ 网络或站点暂时不稳，程序会接着试；
  一直不行就先点「试浏览器」看浏览器起不起得来。
- 兜底永远是 **「直接粘贴饼干登录」**：在浏览器里登录 X 岛后按 F12，把 `usrhash`
  那条粘进去，完全不依赖调试接口。
