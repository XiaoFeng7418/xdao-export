# v0.21.1：修一个只在 Python 3.10 上出现的编译错误

这一版只修一个兼容问题，不改任何行为，也不需要重新配置。

## 为什么

v0.21.0 的合并导出里有一处写法，只有 Python 3.12 及以上才认 ——
f-string 的**表达式部分**里带了反斜杠（`f'{"\n".join(rows)}'`）。打包版用的是 3.12，
所以免安装包完全不受影响；但拿源码跑的用户如果用的是 Python 3.10，程序会在导入
`xdao/exporters/html.py` 时直接失败。

CI 其实早就报了：ubuntu-latest / py3.10 那条作业在「语法检查」步骤就红，只是发布时
只看了打包作业，漏了它。这一版把这个问题一起处理掉。

## 这版做了什么

- 把那行拆成两行普通写法（先算出 `joined`，再插值），输出内容一字不差。
- 新增守卫用例 `tests/test_py310_syntax.py`：扫全仓源码，f-string 的表达式部分
  一旦出现反斜杠或跨行就报红，普通 f-string 照常放行。以后这类问题在本地测试阶段
  就会被拦下，不用等 CI。
- 没有改动的部分：合并导出、抓取、缓存、监控、字号、图片处理、断点续跑，行为都和
  0.21.0 一致。

## 升级建议

用新的免安装包覆盖旧目录即可。如果之前用源码版在 Python 3.10 上跑不起来，这一版
可以直接用了。
