# v0.21.18：界面代码的测试补了一轮

这一版不改功能、不改界面。只补测试，外加清掉一条从来没跑过的坏用例。

## 为什么

上一轮体检里，`xdao/gui.py` 是整个项目里最大的一块（3086 条语句），覆盖率 96%，
剩下那一百多行大多是「出了意外才走」的兜底路径：登录窗起不来、读饼干失败、
旧备份删不掉、更新轮询收尾……这些路径平时不出现，一旦出现又没人盯着，
正是最容易悄悄坏掉的地方。

## 这版做了什么

- 补了 46 条用例（`tests/test_window.py` 148 → 192，`tests/test_gui_entry.py` 178 → 180）：
  登录窗的坏分支与握手、读饼干失败的兜底、自检窗的浏览器检查轮询、清理旧备份与
  暂存目录的 `except`、更新轮询的收尾事件、`run()` 遇 Ctrl+C 安静退出、
  监控一次性检查把图片缓存指到缓存目录；
- 覆盖率（跑全部界面相关用例）：96% → **98%**，未覆盖行 121 → 57；
- 修掉一处用例卫生问题：`tests/test_window.py` 里同一个用例名写了两遍，前一份被
  后一份遮住，从来不会执行——已删掉较弱的那一份，留下的那份还多校验了按钮状态。

剩下的 57 行基本是防御性 `except`（磁盘写不进去、进程杀不掉、系统接口抽风），
继续为它们造假现场收益已经很小，就停在这里。

## 读数

- 测试：2668 项，本机 2658 通过、7 项真机用例默认跳过；
- 新增 46 条用例，产品代码一行没动；
- 界面与导出结果与上一版逐字节一致。

## 升级建议

这一版对使用者没有任何变化，可以不换；想让以后的修改更稳一点，跟着换也不亏。
