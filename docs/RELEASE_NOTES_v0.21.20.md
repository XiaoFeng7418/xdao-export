# v0.21.20：Markdown 存目录时，图片也并发下载了

导出 Markdown 并把图片设成「存到同名目录」时，图片下载也走并发 + 进度 +
可取消的那一套了。成品内容不变。

## 为什么

同一个功能，HTML 与 EPUB 早就做好了：开几个线程一起下、每完成一成报一次
「正在下载图片：x/N」、取消时下载线程立刻抛出去。只有 Markdown 的目录模式
还在一张一张顺着下——图多的串会让人以为卡住了，中途想停也得等当前那张
下完。

## 改了什么

- 图片先并发预取（六路），再逐楼渲染；进度按一成一次报出来；
- 取消可以在下载期间就生效，不用等当前那张图；
- 同一张图在多个楼层出现时只存一份文件，正文里各处都指向它（以前会写出
  「同名-1.jpg」这类副本）；
- 命令行导出也能看到导出器自己的进度了：整理正文、下载图片、渲染 PDF 不再
  长时间一片安静。

## 读数

- 测试：2676 项，本机 2669 通过、7 项真机用例默认跳过；
- 新增 6 条用例（Markdown 5 条 + 命令行 1 条）；
- 成品正文与上一版一致；HTML、EPUB、PDF、TXT 未受影响。

## 升级建议

常用 Markdown 且图多的，值得换这一版。其他用途可以不换。
