# v0.13.1：把「点一下就能升级」真正收尾

v0.13.0 上线后发现两处会让升级白跑或让界面停住的问题，这一版补掉。

## 升级完成之后不再弹「升级中」

换好文件后，程序本来是弹一个「升级中」的消息框再退出。问题在于帮手的耐心是有限的：
它只等老进程 **60 秒**，而这个模态框会一直等用户点「确定」。用户离开座位、或者点慢
一拍，这次升级就白换了 —— 界面明明写着「升级完成」，目录却没换成。

现在直接退出（该落的盘在换文件之前都已经落完了），日志里那句「新版本 x.y.z 已就位，
程序马上自己重启。」就是最后的交代。

## 浏览器资料目录用不了时，判断得更准一点

「换一个资料目录再试」的兜底，原先只认 Windows 的 5 号（拒绝访问）与 32 号
（被占用）错误码；现在同样认 `EACCES` / `EBUSY` 这类系统错误号。Windows 上的
行为不变，Linux 上跑测试时才不会漏判。

（v0.13.0 首次发布时补掉的三件事 —— 点完显示已就位却没换、`%TEMP%` 剩几十 MB、
浏览器登录 WinError 5 —— 见 `docs/RELEASE_NOTES_v0.13.0.md`。）

## 升级以后怎么拿到这一版

**已经装了 v0.13.0 的不用手动下载**：等它自己提示「有新版本」，点一下按钮就行。

## 下载

免安装包：`xdao-export-v0.13.1-win64.zip`（解压后双击 `xdao-export.exe`，不用安装 Python）。

## 这一版没有改什么

界面、导出格式、配置文件、命令行开关都与 v0.13.0 一样，只是把上面两处补严实。
