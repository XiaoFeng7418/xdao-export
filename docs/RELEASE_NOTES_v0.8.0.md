# v0.8.0：PDF 可以自己选纸张和页边距了

这一版把导出的 PDF 从「完全跟着网页的打印样式走」变成**可以自己定**：纸张大小、方向、
页边距、缩放、要不要打印背景、只导出某几页，都能在设置里选，也能用命令行参数指定。

## 这一版改了什么

### 1. 新增「PDF 页面」设置（设置对话框里）

设置里多了一小块「PDF 页面」：

| 项目 | 可选值 |
| --- | --- |
| 纸张 | **跟随网页样式（推荐）** / A4 / A3 / A5 / Letter / Legal |
| 方向 | 纵向 / 横向 |
| 页边距 | **跟随网页样式（推荐）** / 无边距 / 窄（10mm）/ 普通（18mm）/ 宽（25mm），也可以自己填毫米数（0～50） |
| 缩放 | 50% ～ 200%，默认 100% |
| 打印背景 | 勾选后保留底色与背景图（默认勾选） |
| 页码范围 | 留空＝全部；例如 `1-3,5` |

全部默认时**与上一版完全一致**：还是走原来的渲染方式，输出逐字节相同。只有你真的改了
其中一项，程序才会切到另一条渲染通道（浏览器的 DevTools 协议），把纸张/边距这些参数
真正交给浏览器。

### 2. 命令行也能指定（方便批处理与脚本）

```
--pdf-paper {default,a4,a3,a5,letter,legal}
--pdf-orientation {portrait,landscape}
--pdf-margin {default,none,narrow,normal,wide}   或  --pdf-margin-mm 18
--pdf-scale 1.0
--pdf-no-background
--pdf-pages 1-3,5
```

参数写错时会给出中文说明并以退出码 2 结束（例如「PDF 参数有误：边距只支持
default/none/narrow/normal/wide 或 0~50 的毫米数，收到 'thin'」），不会静默忽略。

### 3. 串监控导出也生效

「串监控」是长期后台跑的功能。上一轮接 PDF 选项时只接了手动导出，监控那条路仍在用默认
纸张/边距 —— 那样用户改完设置会以为没保存。现在监控每一轮检查都用同一套 PDF 选项，
命令行 `--watch` 与界面「立即检查一轮」都覆盖到了，并各自补了契约用例钉住。

### 4. 顺手修掉的问题

- **设置里的 PDF 选项一度只在手动导出生效**（见上一条）；
- **`--pdf-scale` 的帮助文本会让命令行解析直接崩**（裸 `%` 被当成格式化占位符），已修；
- **测试曾把用户真实配置写坏**：`tests/test_settings.py` 早期版本没有隔离配置，运行时把
  `%APPDATA%\xdao-export\config.json` 里的 PDF 相关键改成了测试值。这次给整个测试套件加了
  硬守卫：任何用例只要试图**读或写**用户真实配置就直接失败，另加一组专门用例检查这道守卫
  本身有效、且用户配置文件字节不变。（原作者自己跑全量时同样触发过，属实现方的责任，
  已在维护文档里记下教训。）

## 你现在该怎么做

1. 下载下面的免安装包，解压，双击 `xdao-export.exe`。
2. 想让 PDF 用固定纸张（比如打印装订用 A4）：设置 →「PDF 页面」→ 选纸张与页边距 → 保存。
3. 什么都不改就是老样子，输出与上一版一致。

## 下载

- `xdao-export-v0.8.0-win64.zip`（推荐，也是唯一的附件）：**免安装包**，解压后双击
  `xdao-export.exe`；包内附 `诊断写入.ps1` 与 `诊断写入-双击运行.cmd`。
- 单文件版自 v0.5.1 起不再提供：PyInstaller 的单文件版在含中文的路径下会直接报
  `Could not create temporary directory!`，属于打包器的限制，不是程序本身的问题。

## 已知边界（如实说明）

- **「跟随网页样式」是真默认**：纸张与页边距都选默认时，程序把页面自己的
  `@page` 规则交给浏览器，输出与上一版一致。
- **网页自己声明了 `@page { margin: … }` 时，你填的边距会被页面样式盖掉** —— 这是浏览器
  的行为（CDP 的边距参数与页面 CSS 冲突时以页面为准），我们绕不过去，所以保留「跟随网页
  样式」作为推荐项；本程序自己生成的 HTML 不声明 `@page` 边距，因此填了就会生效。
- **PDF 导出仍然需要本机装有 Chrome 或 Edge**（Windows 上基本都有）；打包版在部分机器上
  启动浏览器会失败，这一项功能可能需要从源码运行（`python main.py -f pdf`），详见
  `MAINTENANCE.md` 的「已知限制」一节。
- **登录仍需要真人处理一次验证码**：视觉识别对 X 岛验证码的准确率太低（实测 3 张只认对
  一张半），所以不做自动登录，这一点没有变。

## 测试

`899 collected / 893 passed, 6 skipped`（6 条 skipped 都要显式开关才跑：`XDAO_BROWSER_TEST=1`
拉起真实浏览器、`XDAO_LIVE_NOTIFY=1` 真弹一次系统通知、`XDAO_PDF_TEST=1` 用真浏览器渲染
PDF 并核对纸张尺寸）。本版新增的离线用例覆盖：

- **PDF 选项**：纸张尺寸表与显示名、边距预设与自定义毫米数、缩放截断、页码范围校验、
  非法值回落、`to_cdp_params()` 的换算（含显式纸张时不许带 `preferCSSPageSize`）、
  `describe()` 文案，以及「老配置没有这些键时行为与 v0.7.0 一致」；
- **PDF 渲染路由**：全默认走命令行、改过任何一项走 CDP、**只填页码范围也必须走 CDP**
  （`is_default` 不看页码，是这一版差点漏掉的坑）、`_cdp_params()` 的参数清理、
  CDP 返回结果的 base64 解码与错误分支；
- **接线**：设置界面读写、命令行参数与非法输入的退出码、`create_exporter` 的透传、
  界面导出与串监控两条路都带上了 PDF 选项；
- **配置隔离守卫**：读写用户真实配置必须报错、临时配置往返正常、用户配置文件字节不变。

真机用例（`XDAO_PDF_TEST=1`）4 条：显式 A3 出 A3、全默认跟随页面出 A4、无边距与宽边距
导致的分页差异、以及页码范围截断页数。离线跑测试不会碰网络、不会拉起浏览器，也不会写
用户配置。
