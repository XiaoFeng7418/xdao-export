# v0.17.7：程序起的浏览器窗改成一次性干净配置，不再自动登录 Edge、不再同步

## 为什么

「用浏览器登录」点开后，程序会新起一扇浏览器窗口，`--user-data-dir` 指向一份全新的一次性
资料目录。目录是新的，可账号不是：本机登录着 Windows 账号时，Edge 会走**隐式登录**自动登进
同一个 Microsoft 账号，随后按账号设置同步收藏、密码等数据。

于是一扇「本该什么都没有」的窗口里：登录页弹「正在同步浏览数据」的提示，自动填充里出现云端
保存的密码，整罐饼干里混进 msn / bing 一堆域外域名。

## 这版做了什么

- **关掉隐式登录与同步**：启动参数补 `--disable-sync`，并把 `--disable-features` 从 `Translate`
  扩成 `Translate,msImplicitSignin`。窗口回到「干净的一次性浏览器」：不登账号、不拉同步、
  自动填充里不会出现云端密码、整罐里不会有域外域名的饼干。
- **实测对比**（同一台机器、同一套启动流程，各起一扇新窗等 9 秒后读整罐）：
  改前整罐 11 块、其中 10 块属于微软家族；改后整罐 1 块、微软家族 0 块。
- **新增一个排查开关**（日常用不到）：设了环境变量 `XDAO_LOGIN_DUMP` 时，登录成功后也会在
  临时目录落一份「读罐详单」，用来核对程序读的是不是眼前那扇窗。默认不开，不影响任何行为。
- 登录流程、饼干读取、导出格式、配置文件、命令行开关一律没动。

## 升级建议

直接用新版覆盖旧版即可，配置与导出结果都不变。以前那扇窗会顺带把本机 Microsoft 账号的会话
带进临时资料目录，这一版起不会了；如果之前用「用浏览器登录」时在窗口里登录过 Edge 账号，
可以在 Edge 自己的设置里检查一下已登录设备（与本工具无关，工具从不上传任何数据）。
