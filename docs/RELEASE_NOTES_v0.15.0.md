# v0.15.0：界面与成品的字号都能调

## 这一版加了什么

**一、界面字号（右上角「字号」下拉框）。** 以前界面的字号固定，屏幕小、离得远或者眼神吃力时
只能凑近看。现在右上角多了一个「字号」下拉框，五档：小（0.85 倍）、标准（1.0）、大（1.15）、
更大（1.3）、特大（1.5）。

- 窗口尺寸、左栏宽度与所有文字一起按比例放大，不是只把字放大而框子不动；
- 选完立刻重画界面并记住，下次启动还是这个档；
- 正在导出或监控时不让切（中途重画界面容易丢进度），日志内容与填好的串地址都不会丢；
- 默认仍是「标准」，不动它的话界面和以前一模一样。

**二、成品的正文字号。** 「设置 → ③ 导出」新增「正文字号」，10~28 磅（默认 14）：

- 对 HTML / PDF / EPUB 生效：正文、标题、引用、代码块的磅数一起按这个值走；
- 导出开始时运行日志会写一行「正文字号：N 磅。」，成品拿到手能对得上；
- 命令行是 `--font-size 20`，命令行优先于设置里那个值；
- TXT 与 Markdown 是纯文本，没有字号一说。

**默认值刻意没有动**：这两个设置都留着老默认（界面 1.0 倍、正文 14 磅），所以照旧用的人
看不出任何差别 —— 只有自己去调，界面和成品才会变。

## 这一版的自查

- 全量用例 **1983 passed / 7 skipped**（收集 **1990** 项；比上一版多 59 项，都在字号这条线上）；
- 契约用例（文档事实、版本号一致、使用说明分段、文本卫生、打包清单、公开材料、命令行文档）全绿；
- 逐文件行尾复查：`README.md` / `MAINTENANCE.md` / `HANDOFF.md` 仍是 CRLF，`packaging/使用说明.txt`
  仍是 UTF-8 BOM + 纯 LF；
- 免安装包的 `--version` 输出 `0.15.0`。
