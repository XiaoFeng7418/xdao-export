# v0.3.3：任何错误都只给一句人话，不再弹 traceback

这一版只做一件事：**把没接住的异常全部收干净**。

## 你遇到的问题

用打包版时，如果导出目录填成 `D:\Windows` 这类当前账户写不进去的位置，
程序会弹出一个标题是 **Unhandled exception in script** 的对话框，
里面是一大段 `Traceback ... PermissionError: [WinError 5] 拒绝访问。: 'D:\Windows'`。

看起来像是程序崩了，其实是：命令行入口有一个 `mkdir` 没有包 try/except，
异常一路穿到 PyInstaller 的启动器，被它当成「脚本执行失败」展示出来。

## 这一版做了什么

- **导出目录建不出来时**，直接说明白：

  ```
  失败：导出目录没法创建：D:\Windows\xdao-probe
  拒绝访问。（错误码 13）
  常见原因：这个位置不允许当前账户写入，或者路径里有一段不是文件夹。
  请换一个当前账户可写的目录（例如「文档」下的文件夹）后重试。
  ```

  不再打印 traceback，退出码仍然是 1（方便脚本判断）。

- **命令行入口整体兜底**：`Ctrl+C` → 退出码 130；预料内的错误 → 一句人话；
  预料外的错误 → `失败：XXXError: 具体信息` 并附上 issue 地址。
- **启动阶段也兜底**：连参数解析、读配置、开界面都算在内；
  如果配置文件坏了，会提示可以删掉 `%APPDATA%\xdao-export\config.json` 后重试。
- **界面本身也兜底**：
  - `tk.Tk()` 建不出来、或界面初始化失败时，弹一个说明对话框，
    而不是让 PyInstaller 弹「Unhandled exception in script」；
  - Tk 回调（按钮、定时刷新）里抛出的异常默认是往 stderr 打印的，
    而免安装的打包版**没有 stderr** —— 于是异常会一路穿到启动器变成错误对话框。
    现在改成写进日志面板 + 弹对话框，程序继续运行。
- **控制台输出改成 UTF-8**：打包版以前会把中文按本地代码页解读，
  `xdao-export.exe --version` 显示成 `X������������ 0.3.3`；
  既然这一版的主题是「把错误说清楚」，输出编码也一并修好。
  （提示：由于打包版是「窗口程序」而不是「控制台程序」，
  在 cmd 里跑它本来就不会显示任何输出，`--version` 也一样；
  命令行要看到文字请从源码运行 `python main.py --version`。）
- **图形界面**：
  - 点「开始导出」时**先检查导出目录写不写得进去**，写不进去就弹一个说明对话框，
    不会再抓取几百秒之后才失败；
  - 导出线程里任何没预料到的异常，都会变成日志里的一行（`导出没能开始/继续：…`），
    并把这次导出正常结束掉，界面不会卡在「导出中」；
  - 监控线程同样加了兜底（`监控出错：…`），出错后也会自动回到停止状态。

## 怎么用

和以前一样，推荐**免安装包**：

- `xdao-export-v0.3.3-win64.zip` —— 解压后双击 `xdao-export.exe`，
  `xdao-export.exe` 与 `_internal` 文件夹必须放在一起。
- `xdao-export-v0.3.3.exe` —— 单文件版，更方便携带，
  但会先把内容解压到系统临时目录；在临时目录不可写的环境里会报
  `Could not create temporary directory!`，这时请换免安装包。

## 说明

- 这一版**没有改导出行为**，四种格式（HTML / TXT / Markdown / EPUB）与
  打包版的 PDF 降级逻辑都保持原样；想要真正的 PDF 请从源码运行
  `python main.py <串号> -f pdf`。
- 上一版（v0.3.2）的缓存兜底仍然有效：缓存目录写不进去时会自动换到
  `%LOCALAPPDATA%\xdao-export\.cache`，并在日志里说明。
