# v0.13.4：浏览器登录改用你指定的那个浏览器，并当场说清用的是谁

## 这一版修的是两件小事

**一、设置里手动指定的浏览器，现在「用浏览器登录」也认了。** 以前这个设置只对
PDF 导出生效，浏览器登录还在自己挑 —— 两边不一致最让人糊涂：明明是自己在设置里
填好的 Chrome，点「用浏览器登录」开出来的却是 Edge。现在两边用的是同一个设置。

**二、窗口上会当场写清这次用哪个浏览器。**

    这次用 Edge 打开（C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe）。

以前要等失败、或者等程序自己换了一个浏览器，才会在状态行里提一句；现在点开就知道。
设置里留空时跟随系统默认浏览器（v0.13.3 起），认不出来再按 Edge → Chrome → Chromium
→ Brave 的顺序找。

## 顺带把设置里的说明写清楚了

「PDF 浏览器」那一栏原来只写着「导出 PDF 时调用」，现在写明它同时管「用浏览器登录」，
留空时的挑选顺序也写出来了：**跟随系统默认浏览器，认不出来再找 Chrome 或 Edge**。

## 这一版没有改什么

界面布局（只多了一行小字）、导出格式、配置文件、命令行开关都没动。

## 升级以后怎么拿到这一版

**已经装了 v0.13.3 的不用手动下载**：等它自己提示「有新版本」，点一下按钮就行。

## 下载

免安装包：`xdao-export-v0.13.4-win64.zip`（解压后双击 `xdao-export.exe`，不用安装 Python）。

## 还是连不上的话

先关掉安全软件的浏览器防护、再点一次「重新打开浏览器」；仍然不行就点
**「直接粘贴饼干登录」**：在浏览器里登录 X 岛后按 F12，把 `usrhash` 那条粘进去，
一样能登录，完全不依赖调试接口。
