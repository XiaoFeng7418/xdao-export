# v0.13.5：多了一条 `--check-browser`，能当场查出「浏览器到底能不能起来」

## 为什么加它

`--selftest` 里那行「浏览器」一直只回答**找不找得到**：

    [通过] 浏览器：（自动找到）Edge：C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe

可用户真正卡住的地方是「**找得到，但一起来就被拦下**」（Edge 退出码 21）。这种情况下
自检显示一切正常，点「用浏览器登录」却永远失败 —— 排查只能靠一轮轮问。

## 现在可以直接问它

    xdao-export.exe --check-browser
    xdao-export.exe --check-browser-json     （结果按 JSON 输出，便于贴出来）

它会**真的把浏览器启一次**（写一个临时资料目录，试完立刻关掉），回答三件事：

    [可以] Edge：能起来，Edg/154.0.4258.48，调试端口 64150 答得上话（0.5 秒）。
    结论：可以用 Edge 打开浏览器登录（C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe）。

起不来的话，会把原因和退出码直接说出来：

    [不行] Edge：Edge 刚起来就退出了（退出码 21）。
    结论：本机这些浏览器都起不来，所以「用浏览器登录」暂时用不了。
    常见原因：安全软件（火绒、360 之类）拦下浏览器进程或本地调试端口。

挨个试的顺序就是「用浏览器登录」真正会用的顺序：**设置里指定的那个 → 系统默认浏览器
→ Edge → Chrome → Chromium → Brave**，有一个能用就停。

## 一个陷阱顺手也堵上了

调试端口文件写出来**不等于**那个端口能连（v0.13.2 修的就是这段时差）。所以
`--check-browser` 除了等端口文件，还会真的问一句调试接口（`/json/version`）；
答不上话就不算通过。这条规则来自实测：拿 `cmd.exe` 冒充浏览器传进去，它被
Chromium 那串参数当命令跑，退得比第一次检查还快，光看「进程还在不在」会误判成「可以」。

## 这一版没有改什么

界面、导出、配置、升级流程都没动；只是多了一个命令行开关，
`--selftest`（那只查「找得到找不到」、不改任何东西）也保持原样。

## 升级以后怎么拿到这一版

**已经装了 v0.13.4 的不用手动下载**：等它自己提示「有新版本」，点一下按钮就行。

## 下载

免安装包：`xdao-export-v0.13.5-win64.zip`（解压后双击 `xdao-export.exe`，不用安装 Python）。

## 还是登录不上

先跑一次 `--check-browser` 看看结论；然后关掉安全软件的浏览器防护再试一次。
都不行就用弹窗上的 **「直接粘贴饼干登录」**：在浏览器里登录 X 岛后按 F12，把
`usrhash` 那条粘进去，一样能登录，完全不依赖调试接口。
