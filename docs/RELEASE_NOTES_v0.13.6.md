# v0.13.6：环境自检里多了一个「试浏览器」，点一下就知道浏览器到底起不起得来

## 为什么

v0.13.5 加了 `--check-browser`，能真的把浏览器启一次、回答「起不起得来」。可它是**命令行**
开关 —— 双击 `xdao-export.exe` 打开界面的用户看不到它，还是只能看着「打开浏览器失败」
那句话猜。

这一版把同一件事搬进界面：**「运行日志」右上角的「自检」→ 底部「试浏览器」**。

## 点了会发生什么

- 它按「用浏览器登录」真正会用的顺序试（**设置里指定的那个 → 系统默认浏览器 → Edge →
  Chrome → Chromium → Brave**），有一个能用就停。
- 每个浏览器都是**真启动一次**，用的是临时资料目录，试完立刻关掉 ——
  **不碰你自己浏览器里的登录状态**。
- 右下角会显示当下在试谁（`正在试 Edge（C:\...\msedge.exe）…`），结论直接写进自检文本：

      [可以] Edge：能起来，Edg/154.0.4258.48，调试端口 64150 答得上话（0.5 秒）。
      结论：可以用 Edge 打开浏览器登录（C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe）。

  起不来的话会给出原因和退出码，整段结果和别的自检内容一样能**一键复制**贴出来。

- 探测**不换浏览器、不换资料目录**：它要如实回答「这一个行不行」，所以和登录那条路的
  兜底逻辑是分开的（登录时该换就换，探测时不许换）。

## 没改什么

导出、配置、升级流程、命令行开关都没动；`--check-browser` 和
`--check-browser-json` 照旧可用。自检默认的那几项仍然**只读不动** ——
「试浏览器」是单独一个按钮，你不点它就不会启动任何浏览器。

## 升级以后怎么拿到这一版

**已经装了 v0.13.5 的不用手动下载**：等它自己提示「有新版本」，点一下按钮就行。

## 下载

免安装包：`xdao-export-v0.13.6-win64.zip`（解压后双击 `xdao-export.exe`，不用安装 Python）。

## 还是登录不上

先点一次「试浏览器」看结论：

- 说**可以用**，但登录还是失败 → 多半是浏览器起来了、登录页或调试接口被拦，
  把结果复制出来；退路是弹窗上的 **「直接粘贴饼干登录」**。
- 说**都起不来** → 关掉安全软件（火绒、360 之类）的「浏览器防护 / 主页锁定 / 驱动级防护」
  再试一次，或者把浏览器加进白名单。
- 「直接粘贴饼干登录」永远可用：在浏览器里登录 X 岛后按 F12，把 `usrhash` 那条粘进去，
  完全不依赖调试接口。

> **更正（v0.14.0，2026-10-11）**：这一版当时把「写不进去」只归到 Windows 的「受控文件夹访问」。后续实测又定案了两类成因 —— ①程序是从一个「被限制写入的目录」里启动的（把程序整个文件夹挪到不受限的位置即可）；②第三方安全软件的「文件保护 / 重要文件保护」按「程序有没有签名」判定（它们的「信任区」通常只管病毒查杀，要放行写入得在「防护中心 → 系统防护 → 文件保护」里加白）。三类成因与怎么一眼分清，见 `README.md` 与包内`使用说明.txt` 的同一段。
