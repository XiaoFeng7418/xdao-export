# v0.24.1：导出细节与随包许可打磨

本版继续支持 X 岛（nmbxd1.com）与 B 岛（bog.ac）公开串，B 岛无需登录。

- EPUB：复核 v0.22.1 已落实的单份图片存储，补强 X 岛单图与 B 岛多图在 embed、url、drop 模式下的回归检查，核对 XHTML、manifest 与 mimetype 条目；相对 v0.24.0 不宣称包体积减半。
- TXT 导出与自动标题保留正文里的字面尖括号，同时清理真实 HTML 标签。
- 无 Tk 时完整读取配置已有守卫；本版进一步将配色名与界面字号的纯校验规则从 Tk 图形库中分离，验证全部配置字段且不尝试导入 Tk，并保留原主题模块的兼容导出。
- 构建时从实际构建环境收集第三方许可原文并核对覆盖情况，包内提供组件来源清单；中英文首页同步说明两站点的导出能力。

本版不调整界面布局或配色，不增加导出格式或命令行开关。历史审计报告保留原文。

## 附件

- `xdao-export-v0.24.1-win64.zip` 是 64 位 Windows 免安装包。解压后双击 `xdao-export.exe`，无需安装 Python。
- `xdao-export-v0.24.1-win64.zip.sha256` 是配套的 SHA256 校验文件。
