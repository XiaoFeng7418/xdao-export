# v0.14.0：导出范围（页数上限 + 串号截止），另修两处

## 这一版改什么

### 1. 新功能：导出范围

- **最多页数**：每个串最多抓 N 页（**含第 1 页**）。留空或填 `0` = 不限；不限时程序仍保留
  5000 页的安全阀。命令行是 `--max-pages N`。
- **串号截止**：抓到某个串号为止，并且**包含它本身** —— 它后面的串一律跳过。界面里那个输入框
  右边就写着「（含它）」，命令行是 `--until <串号>`。截止串号没出现在列表里时，列表里串号
  不超过它的那些串都会导（含等于）：拿一串编号去卡范围时，「截止值落在两个串中间」是常态，
  不该因为差一个号就把整整一段丢掉。
- 两个开关都不写时用设置里存的那份；都没有就是不限。
- 撞上页数上限时，汇总里会写明「这次只抓到第 N 页（这次要抓的范围比这长）」，不会假装抓全。
- 缓存里存着超过上限的页时不会早退，会落到抓取路径按上限裁剪 —— 不多发请求，也不会把超出
  范围的内容混进成品。

### 2. 修一处诊断瑕疵

浏览器资料目录带中文时，运行日志里那段「罐路径」会显示成乱码（`D:\小玩意\…` 变成
`D:\С����\…`）：取浏览器命令行那一步走的是 powershell，而中文 Windows 上 powershell 5.1
的输出是 GBK，程序却按 UTF-8 解。现在在脚本开头钉住输出编码为 UTF-8。

### 3. 「写不进去」的说明按实测改正

原来只讲「去 Windows 安全中心把程序加进受控文件夹访问的白名单」。实测又定案了两类成因，
现在 `README.md`、包内 `使用说明.txt`、自检劝告、导出时的错误说明、诊断脚本统一成三类，
并写明怎么一眼分清：

1. **程序是从一个「被限制写入的目录」里启动的**（沙箱、受限令牌这类环境）—— 把程序整个
   文件夹挪到不受限的位置即可；
2. **Windows 的「受控文件夹访问」（勒索软件防护）** —— 走安全中心那条路径放行；注意这个开关
   处于关闭状态时，第 1 类照样会拦；
3. **第三方安全软件的「文件保护 / 重要文件保护」** —— 按「程序有没有签名」判定；它们的
   「信任区」通常只管病毒查杀，要放行写入得在「防护中心 → 系统防护 → 文件保护」里加白。

判断方法：双击包里的 `诊断写入-双击运行.cmd`（它测的是 PowerShell 进程）。报告里桌面/文档是
「写不进去」而 `%LOCALAPPDATA%` 是「能写」就是第 2 类；报告里**全是「能写」而程序自己仍写不
进去**就是第 1 或第 3 类。四份历史发布说明（v0.5.2 / v0.5.3 / v0.13.6 / v0.13.29）各加了一行
标注清楚的「更正（v0.14.0）」，历史记录本体不动。

## 还没接的地方

`--max-pages` 对监控模式（`--watch`）无效：监控轮次走的是 `xdao/watcher.py` 的 `check_once()`，
它没有页数参数（`--until` 会截断监控列表本身）。要接得同时改监控列表的持久化，留到后面。
