## 本次更新

**v0.2.1 是一个发布形式的修复版**：功能与 v0.2.0 完全相同，只改了版本号与打包/发布方式。

### 换了默认下载

v0.2.0 只提供 PyInstaller **单文件版**，它在**系统临时目录不可写的环境里会直接打不开**，
弹出 `Could not create temporary directory!` —— 那是启动器在 Python 代码运行之前就失败了，
跟程序本身无关。

从本版开始，**默认提供免安装包**：

| 附件 | 说明 |
|---|---|
| `xdao-export-v0.2.1-win64.zip` | **推荐**。解压后双击 `xdao-export.exe`。启动时不做任何解压，受限环境也能用。 |
| `xdao-export-v0.2.1.exe` | 单文件版，只有一个文件更好携带；每次启动会把内容解压到系统临时目录。 |

免安装包解压后的结构（`xdao-export.exe` 与 `_internal` **必须放在一起**）：

```
xdao-export-v0.2.1-win64/
├─ xdao-export.exe      ← 双击这个
├─ _internal/           ← 运行库，不要删、不要单独拷走 exe
└─ 使用说明.txt
```

### 功能（与 v0.2.0 相同）

- 四种导出格式：HTML（图片内嵌）/ TXT / Markdown / EPUB；
- 断点续传与增量更新：33 页 / 626 楼的长串，第二次导出只花 1 次请求；
- 图片缓存、只看指定饼干、文件名模板；
- 串更新监控：定时检查新回复并自动导出；
- 可配置代理、请求间隔、超时与重试（429 / 5xx 指数退避）；
- 182 个离线单元测试。

### 使用提示

- 串越长收益越明显：首次导出逐页抓取，之后靠缓存快得多。
- 图片全部内嵌会让 HTML / EPUB 很大（600 多楼的图串可达数百 MB）；体积敏感时用 TXT / Markdown，或把 EPUB 图片模式设为「仅链接」。
- 请遵守 X 岛的使用规则，控制抓取频率，导出的内容仅供个人备份。
