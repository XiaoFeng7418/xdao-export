# v0.7.0：登录不用再碰开发者工具

这一版把「登录」这件事换了个做法：**由程序开一个独立的小浏览器窗口，你在里面像平常
一样登录 X 岛，饼干（userhash）由程序自己取回来**。「打开开发者工具 → 在 Cookie 里翻
userhash → 只复制 `=` 到 `;` 之间那一段」这条路，从此不需要了。

## 这一版改了什么

### 1. 新增「用浏览器登录」（推荐）

在登录对话框里点「用浏览器登录」，程序会：

1. 用系统里的 Edge / Chrome 打开一个窗口（Windows 自带的 Edge 就够），使用一个
   **独立的浏览器配置目录**（放在程序的配置目录下，不碰你平时用的那套浏览器配置）；
2. 你在那个窗口里正常登录 X 岛 —— **验证码仍然要人来认，程序不代替你登录**；
3. 登录成功后，程序通过 Chrome DevTools Protocol 把 `userhash` 饼干读回来
   （HttpOnly 的也读得到），设进当前会话，然后关掉自己开的浏览器窗口。

整个过程不用按 F12，也不用抄任何值。机器上找不到 Edge / Chrome / Chromium / Brave 时，
「用浏览器登录」会直接说明情况，**账号密码登录与粘贴登录都还在**，不会因为少一个浏览器
就用不了。

### 2. 粘贴登录更宽容

「直接粘贴饼干登录」现在接受**整段 cookie**：在浏览器里登录 X 岛用户系统之后，把 cookie
整段复制、整段粘贴进来即可 —— `userhash=...` 也在这段文字里，程序会自己把值摘出来
（`userhash=xxx`、单独一个裸值、带引号或换行的粘贴都认）。粘贴的内容里确实没有
userhash 时，会弹一句人话提示说明没找到，而不是抛一个看不懂的异常。

提示语里也明确写了：**不需要打开开发者工具**。

### 3. 修掉验证码图片的 gzip 隐患

实测：登录页的验证码接口把 PNG **包在 gzip 里**发回来，HTTP 头却写着 `image/png`。
程序原先只认 `Content-Encoding: gzip`，所以这份响应体一直没有被解开 —— 界面用的 Tk
恰好能吃下这种字节，于是问题从没暴露；但只要换一处按 PNG 解析这份数据的地方，拿到的
就是一个坏文件。现在多兜一层：按 gzip 魔数判断，是压缩包就解开，解不开（响应本身坏了）
就原样交出去，由调用方按自己的方式报错。

## 你现在该怎么做

1. 下载下面的免安装包，解压，双击 `xdao-export.exe`。
2. 登录时优先点「用浏览器登录」，在弹出的窗口里登录一次即可。
3. 不想开浏览器窗口，就用「直接粘贴饼干登录」把整段 cookie 贴进来；账号密码 + 验证码
   登录的方式也仍然保留。

## 下载

- `xdao-export-v0.7.0-win64.zip`（推荐，也是唯一的附件）：**免安装包**，解压后双击
  `xdao-export.exe`；包内附 `诊断写入.ps1` 与 `诊断写入-双击运行.cmd`。
- 单文件版自 v0.5.1 起不再提供：PyInstaller 的单文件版在含中文的路径下会直接报
  `Could not create temporary directory!`，属于打包器的限制，不是程序本身的问题。

## 测试

`493 collected / 491 passed, 2 skipped`（两条 skipped 都要显式开关才跑：`XDAO_BROWSER_TEST=1`
会拉起真实浏览器，`XDAO_LIVE_NOTIFY=1` 会真弹一次系统通知）。
这一版新增的离线用例覆盖：

- **验证码响应体**：gzip 包配 `image/png` 头要解压、普通字节不动、坏包按原样返回；
- **登录表单**：验证码是压缩包时，`LoginForm.captcha_bytes` 出来就是真 PNG 的魔数；
- **响应头记录**：键统一小写（判断要不要解压就靠它）；
- **粘贴解析**：整段 cookie、带引号换行、粘错东西、取消，四条路径都不抛异常；
- **浏览器登录库**：浏览器路径发现、启动参数、`DevToolsActivePort` 解析、WebSocket
  帧收发、各种粘贴形态的 `parse_userhash_input`、应用饼干用的 JS 片段；
- **「用浏览器登录」对话框**：成功取回 userhash、用户关掉浏览器后可以重开、关窗时线程与
  浏览器进程都收干净、读饼干时报错会落到对话框上，另加两条契约守卫用例（测试替身必须覆盖
  库真正调用的会话方法；`LoginBrowser.start()` 不许自己开 CDP 会话）。

其中「浏览器登录库」整块是这一版新增的，启动真浏览器的那条集成用例默认跳过，
离线跑测试不会碰网络、也不会拉起任何浏览器。
