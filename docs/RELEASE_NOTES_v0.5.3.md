# v0.5.3：写不进去就自动换个地方，诊断脚本双击就能看

这一版解决的是一件很气人的事：**抓取全部成功，最后一个文件都存不下来**。

## 出了什么问题

有用户的导出目录设在桌面下新建的文件夹里，程序把串子抓完、图片也下完了，
落盘时却报：

```
[1/1] 失败：PermissionError: [Errno 13] Permission denied:
'C:\Users\...\Desktop\新建文件夹\肥哥们，大家现在 AI 写文…….html'
```

桌面、文档、图片、视频默认在 Windows **受控文件夹访问**（勒索软件防护）的保护范围内，
没进白名单的程序一律不许往那里写文件。上一版只是把这件事说清楚了，抓取成果照样白费。

## 这一版改了什么

- **导出目录写不进去时，自动换到一个能写的位置**：优先用
  `%LOCALAPPDATA%\xdao-export\导出`（属于本程序的用户目录，不受受控文件夹访问保护），
  其次 `%TEMP%\xdao-export`。换地方之前会先真的试写一次，确认能写才用。
- **换地方会明说，不偷偷换**：界面上弹出提示、日志里写明"原目录为什么不能用、这次放在哪"，
  导出目录那一栏也会跟着显示新位置。原来的设置不改动 —— 下次启动仍按你设的位置试。
- **你自己选的目录不会被改掉**：在「更改…」里亲手挑过导出目录之后，程序只报错、不擅自换地方。
  命令行用 `-o` 指定目录时同理，只打印一句"注意："。
- **兜底目录不会覆盖上一次的成品**：已经存在 `导出` 时会依次用 `导出-2`、`导出-3`。
- **`诊断写入.ps1` 现在会把结果存成文件**：以前双击运行窗口一闪就没了、什么也看不到。
  现在结束时会把完整报告写成 `诊断结果-年月日-时分秒.txt`（优先放在脚本旁边），
  并打印"已保存：<路径>"，最后等你按回车才关闭。
  报告里新增：PowerShell 版本、桌面本身能不能写、`%LOCALAPPDATA%\xdao-export\导出`
  能不能写、配置里记着的导出目录与缓存目录能不能写、受控文件访问的**已放行程序**名单。
- **多了一个 `诊断写入-双击运行.cmd`**：不想记命令的，直接双击它即可。

## 你现在该怎么做

1. 下载下面的免安装包，解压，双击 `xdao-export.exe`。
2. 导出目录**保持你原来的设置**直接开始导出。写不进去时它会自己换到
   `C:\Users\<你>\AppData\Local\xdao-export\导出`，并告诉你成品在哪。
3. 如果连自动换的地方也写不进去，把 `诊断写入-双击运行.cmd` 双击跑一次，
   把生成的 `诊断结果-*.txt` 发给维护者。
4. 想让程序能直接写进桌面/文档：Windows 安全中心 → 病毒和威胁防护 →
   勒索软件防护 → 受控文件夹访问 → 允许应用通过，把 `xdao-export.exe` 加进去。

## 下载

- `xdao-export-v0.5.3-win64.zip`（推荐，也是唯一的附件）：**免安装包**，解压后双击
  `xdao-export.exe`；包内附 `诊断写入.ps1` 与 `诊断写入-双击运行.cmd`。
  不做任何解压动作，中文路径与受限环境都能启动。
- 单文件版自 v0.5.1 起不再提供：PyInstaller 的单文件版在含中文的路径下会直接
  报 `Could not create temporary directory!`，属于打包器的限制，不是程序本身的问题。
