# v0.13.20：登录慢一点就再也领不到饼干（0.13.18 真机复现）

## 现象

「用浏览器登录」在 0.13.18 上仍然失败，而且是一种很气人的失败：浏览器里明明登录好了
（真机截图里账号名已经显示在页面上），程序却一路等到超时，最后那句诊断还是
「自动取饼干这条路试过了：浏览器里还是没有 userhash。」

## 原因

程序打开浏览器后把标签页停在登录页，头两次「去饼干页领饼干」都在登录页上**什么都没碰**
就返回了（结论是「还没登录」）—— 可这两次机会照样被扣掉。等你打完账号密码登进去，
两次已经用完：之后每轮只会重读饼干罐，而 userhash 只有真去「应用」那一下（导航到站点的
`switchTo` 地址）才会被主站种下。于是「登录成功」和「程序看到登录」之间永远差一步。

## 改法

- 只有**真动过**你标签页的那一次才扣次数：登录页上的尝试不扣，你登进去以后下一次轮询
  （最多 5 秒）就会去领饼干。
- 超时那句话改成按顺序列出试过的几步（①②③），不再只留最后一条 —— 收尾那条
  「还是没有 userhash」信息量最小，却会把「这个窗口里还没登录」盖掉，截图上看不出卡在哪。

程序逻辑只动这两处，界面布局、导出结果与 0.13.19 完全一致。
